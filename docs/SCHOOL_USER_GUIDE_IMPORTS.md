# คู่มือโรงเรียน — การนำเข้าและจัดการข้อมูลนักเรียน (10.13B)

> **Historical snapshot (ติดป้าย 6 ก.ย. 2569):** เอกสาร Phase 10.13B (11 มิ.ย. 2569) — ชื่อปุ่มและชื่อสถานะรายแถวในเอกสารนี้ไม่ตรงกับหน้าจอปัจจุบันแล้ว ห้ามใช้อบรมหรืออ้างอิง
> ฉบับที่ใช้จริง: `docs/manual-html/user-guide-school.html` งานที่ 4–5 (https://schoolbuslampang.com/manual/user-guide-school.html) · ชุดอบรม: `docs/manual-training-2026-08/04-school-full.md`

โรงเรียนทำงานเหล่านี้ได้เองทั้งหมดผ่านหน้าเว็บ ไม่ต้องติดต่อผู้ดูแลระบบเพื่อแก้ฐานข้อมูล

## 1. นำเข้านักเรียน (Import)

1. หน้า **ค้นหา/จัดการนักเรียน** → ปุ่มนำเข้า → เลือกไฟล์ (Excel/CSV)
2. ระบบจะ **แสดงตัวอย่าง (Preview)** ก่อนเสมอ — ยังไม่บันทึกข้อมูล
3. แต่ละแถวจะมีสถานะ เช่น
   - **เพิ่มใหม่ได้** (INSERT_NEW) — นักเรียนใหม่
   - **รหัสซ้ำต่างโรงเรียน** — นำเข้าเป็นคนละคนได้ (ไม่ใช่การย้าย)
   - **รหัสซ้ำในโรงเรียน** — ข้าม (กันข้อมูลซ้ำ)
   - **ข้อมูลผู้ปกครองไม่ตรง** — เลือกยืนยันแก้ไขได้
   - **นักเรียนเคยถูกลบ** — เลือกกู้คืน (reactivate) ได้
   - **แถวซ้ำในไฟล์เดียวกัน** (DUPLICATE_ROW_IN_FILE) — นำเข้าไม่ได้ ต้องแก้ไฟล์
4. กด **นำเข้า (Apply)** — เลือกเฉพาะแถวที่ต้องการได้ ระบบบันทึกเฉพาะแถวที่เลือก

## 2. แก้ข้อมูลผู้ปกครอง (Guardian update)

ถ้าแถวขึ้น “ข้อมูลผู้ปกครองไม่ตรง” ให้ติ๊กยืนยัน — ระบบจะอัปเดตเฉพาะแถวที่ยืนยัน
และแสดงค่าก่อน→หลัง ทุกการแก้ไขถูกบันทึกประวัติ (audit)

## 3. กู้คืนนักเรียนที่ถูกลบ (Reactivation)

ถ้าแถวขึ้น “นักเรียนเคยถูกลบ” (ในโรงเรียนเดียวกัน) ให้ติ๊กยืนยันกู้คืน — ระบบจะ
**ใช้รหัสนักเรียนเดิม ไม่สร้างใหม่** และบันทึกประวัติ

## 4. ประวัติการนำเข้า (History) + รายงาน (Report)

- ปุ่ม **ประวัติการนำเข้า** → ดูชุดนำเข้าย้อนหลัง → เปิดดูรายละเอียดรายแถว
- **ดาวน์โหลดรายงาน (CSV)** ได้แม้ปิดหน้าต่างไปแล้ว (เปิดจากประวัติ)

## 5. ย้อนกลับการนำเข้า (Rollback)

- ในรายละเอียดชุดนำเข้า เลือกแถวที่ต้องการย้อนกลับ → ใส่เหตุผล → ยืนยัน
- ระบบจะ **ปิดใช้งาน (soft-delete) เฉพาะนักเรียนที่ถูกเพิ่มจากชุดนำเข้านี้เท่านั้น**
  ไม่แตะนักเรียนเดิม/ต่างโรงเรียน/ที่อัปเดตผู้ปกครอง/ที่กู้คืน — และทำซ้ำได้อย่างปลอดภัย

## 6. ปัญหารถในไฟล์นำเข้า (Vehicle blockers)

ในหน้าตัวอย่างนำเข้า แต่ละแถวที่ติดปัญหารถจะมีปุ่ม/คำแนะนำ:

- **ไม่พบรถ (VEHICLE_NOT_FOUND)** → “เพิ่มรถได้ที่เมนูจัดการรถ” แล้วตรวจไฟล์อีกครั้ง
  (ระบบไม่สร้างรถอัตโนมัติจากการนำเข้า)
- **รถถูกปิดใช้งาน (VEHICLE_SOFT_DELETED)** → ปุ่ม **“ขอกู้คืนรถ”** — ส่งคำขอให้ผู้ดูแล
  ตรวจสอบ (ระบบไม่กู้คืนอัตโนมัติ)
- **ทะเบียนไม่ระบุจังหวัด** → แก้ไฟล์ให้ระบุจังหวัดของทะเบียนให้ชัดเจน

## 7. ขอโอนย้ายนักเรียน (Transfer)

ถ้านักเรียนต้องย้ายไปโรงเรียนอื่นจริง ๆ ให้ใช้ปุ่ม **“ขอโอนย้ายนักเรียน”** ในหน้าข้อมูล
นักเรียน → เลือกโรงเรียนปลายทาง + เหตุผล → ส่งคำขอ **ระบบจะไม่ย้ายข้อมูลอัตโนมัติ ต้องรอ
ผู้ดูแลระบบอนุมัติ** ติดตามสถานะคำขอได้ในหน้าต่างเดียวกัน และยกเลิกคำขอที่ยังรออนุมัติได้

> ทุกการกระทำ (นำเข้า/แก้ไข/กู้คืน/ย้อนกลับ/คำขอ) ถูกบันทึกประวัติ และจำกัดสิทธิ์เฉพาะ
> ข้อมูลของโรงเรียนตนเองเท่านั้น
