## สิ่งที่ทำในวันนี้

### 1. Roleplay Audit (5 parallel subagents)

จำลองตัวเองเป็นผู้ใช้ 6 Roles (Driver / School / Parent / Admin / Province / Transport / Affiliation) เดินตาม user journey จริง อ่านโค้ดทีละบรรทัด พบ **29 issues**:

- **CRITICAL 5** — geofence ส่ง LINE ไม่ถึงผู้ปกครอง, geofence รับ NaN, ETA คืน NULL เงียบ, LIFF token ไม่ validate
- **HIGH 6** — emergency NULL vehicle, checkin ซ้ำได้, shift flag ไม่สอดคล้อง, "สถานะ" ไม่บอกสาเหตุ
- **MEDIUM 9** — GPS hook ล้มเงียบ, memory leak, race condition, phone validation mismatch
- **LOW 9** — ETA speed hardcoded, TTL สั้น, pagination ขาด

ผล audit เก็บใน `docs/roleplay-audit-2026-06-24.md`
