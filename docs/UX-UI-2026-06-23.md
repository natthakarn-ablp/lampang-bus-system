## แนวทาง (สำคัญ)

ดึง **ความประณีต + micro-interaction ที่มีความหมาย** จาก 21st.dev และ motionsites.ai มาใช้ **ผ่านกรอบ impeccable + DESIGN.md เดิม** — และ **ปฏิเสธ** สิ่งที่ขัดระบบ: glassmorphism, 3D, cinematic transition, neon, gradient ตกแต่ง (สิ่งที่ impeccable เรียกว่า "AI slop" และ DESIGN.md ห้ามไว้)

หลัก motion: **"motion อธิบายการเปลี่ยนสถานะ ไม่ใช่ของตกแต่ง"** — ทุก animation ≤300ms และเคารพ `prefers-reduced-motion`

## สิ่งที่ทำ

### 1. Motion foundation (reuse ได้ทั้งแอป)
- `tailwind.config.js` — keyframes `fade-in`, `scale-in` (+`fade-in-up` เดิม)
- `index.css` — utility `.stagger-children` (เผยรายการทีละชิ้น, `forwards` กันค้างซ่อน, reduced-motion = แสดงทันที)

### 2. ระดับทั้งแอป (propagate ฟรีทุกหน้า)
- `components/Layout.jsx` — **page transition**: เนื้อหา fade-in ตอนเปลี่ยน route (keyed by pathname, motion-safe)
- `components/ui/KPIGrid.jsx` — การ์ด KPI **stagger entrance** ตอน dashboard โหลด

### 3. หน้า flagship
- `pages/Login.jsx` — redesign เต็ม: ใช้ design token (`surface/brand/ink`), การ์ด scale-in, โลโก้ navy fade-in, input focus ring brand + touch 44px, ปุ่ม spinner + active press, error เป็น semantic + fade-in, trust line
- `pages/province/DeploymentReadiness.jsx` — แก้คลาส tailwind ที่ไม่มีจริง (`border-line`/`text-accent`/`divide-line`) → token จริง + AppCard + StatusBadge + progress bar + row hover + stagger

### 4. Shared components — รีวิวครบทุกตัว
- `ui/AppCard.jsx` — เพิ่ม prop `interactive` (hover lift + focus ring ตาม token, reuse ได้)
- `ui/RiskCard.jsx` — **แก้ anti-pattern**: เลิกใช้แถบสีซ้าย 4px (`before:` bar ที่ DESIGN.md ห้าม) → ใช้ **icon chip สี semantic + StatusBadge** (สื่อระดับด้วยสี+ไอคอน+ข้อความ) + เลิก `uppercase tracking` บนข้อความไทย
- `ui/AttentionCard.jsx` — hover ใช้ token `shadow-elevate` + lift + focus ring brand ให้ตรงระบบ
- `components/LoadingState.jsx`, `components/ErrorState.jsx` — fade-in (motion-safe)
- `ui/AlertBanner.jsx` — full border แทน `border-l-4` (ตรงกฎ "ห้ามใช้แถบสีตกแต่ง")
- ตรวจแล้วสะอาด/compliant (ไม่ต้องแก้): CommandHero, KPIStat, StatusBadge, StatusStepRail, LiveKpiCard, SectionTitle, DashboardSection
