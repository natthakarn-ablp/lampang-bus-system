คู่มือนี้สำหรับผู้ดูแลระบบของหน่วยงาน ผู้ดูแลระบบมีสิทธิ์สูงสุดในระบบ คุณทำสิ่งเหล่านี้ได้

  • สร้างและดูแลบัญชีผู้ใช้ทุกบทบาท (สร้าง แก้ไข รีเซ็ตรหัส ระงับ ลบ)
  • อนุมัติคำขอโอนย้ายนักเรียน และคำขอเกี่ยวกับรถ
  • แก้ปัญหาข้อมูลคนขับ เช่น กู้คืนบัญชี ย้ายไปรถใหม่ ปิดใช้งาน

  • เข้าหน้าของโรงเรียน สังกัด จังหวัด และขนส่งได้ เพื่อช่วยแก้ปัญหาแทน

ภาพ: เมนูบัญชีที่มุมขวาบน (ภาพจากบัญชีโรงเรียน ของผู้ดูแลระบบมีเมนู ความปลอดภัยบัญชี เพิ่มมา)

งานประจำวัน (ทำตามลำดับ)

  1. เปิด ศูนย์ควบคุมระบบ ดูว่ามีงานค้างอะไร
  2. อนุมัติคำขอที่ค้าง (โอนย้ายนักเรียน / เกี่ยวกับรถ)
  3. ดูแลบัญชีผู้ใช้ที่มีปัญหา
  4. เปิดดู เรื่องที่ต้องมีส่วนร่วม ว่ามีเรื่องใหม่ไหม

1. ดูศูนย์ควบคุมระบบ

หลังเข้าสู่ระบบ ระบบจะเปิดหน้า ศูนย์ควบคุมระบบ ให้เอง อ่านจากบนลงล่าง

  1. ดูกล่องสรุปด้านบน
    • สีเหลือง มีคำขอรออนุมัติ N รายการ = มีคำขอค้าง กด ตรวจคำขอ เพื่อไปอนุมัติ
    • สีเขียว ระบบทำงานปกติ = ไม่มีคำขอค้าง
  2. ดูการ์ด ต้องทำวันนี้
    • ผู้ใช้ต้องดูแล = บัญชีที่ยังไม่เคยเข้าใช้ หรือยังต้องเปลี่ยนรหัสผ่าน กด ดูรายชื่อ
    • รายการที่ถูกลบใน 24 ชม. = ไว้ตรวจย้อนหลัง ไม่ใช่สัญญาณอันตราย กด ดูประวัติ
    • ถ้าไม่มีอะไรค้าง จะขึ้น ไม่มีงานค้าง
  3. ดูตัวเลขหลัก: ส่งเช้าทั้งจังหวัด · รับเย็น · เหตุฉุกเฉิน 7 วัน · บัญชีที่เปิดใช้
  4. กด รีเฟรช ที่มุมขวาบน เมื่อต้องการตัวเลขล่าสุด

สีบนหน้าจอ: เขียว = เรียบร้อย · เหลือง = ต้องติดตาม · แดง = ต้องรีบดู · เทา = ยังไม่เริ่ม ช่อง รับเย็น ขึ้น ยังไม่เริ่มรอบ ก่อนรอบเย็นเป็นเรื่องปกติ

ภาพ: ศูนย์ควบคุมระบบ

ทำเสร็จแล้วจะเห็น: รู้ว่าวันนี้มีคำขอหรือบัญชีที่ต้องดูแลกี่รายการ

2. อนุมัติคำขอโอนย้ายนักเรียน

โรงเรียนส่งคำขอเมื่อนักเรียนย้ายโรงเรียน หรือเมื่อบันทึกโรงเรียนผิด นักเรียนจะยังไม่ถูกย้ายจนกว่าคุณจะอนุมัติ

  1. เปิดเมนู คำขอโอนย้ายนักเรียน
  2. เลือกตัวกรอง รออนุมัติ
  3. กด เปิดดู ที่คำขอ แล้วอ่านรายละเอียดและคำเตือน
  4. กด อนุมัติและดำเนินการโอนย้าย หรือ ไม่อนุมัติคำขอ
  5. พิมพ์ หมายเหตุผู้ดูแล (ต้องกรอก)
  6. กด ยืนยันอนุมัติและโอนย้าย หรือ ยืนยันไม่อนุมัติ

ภาพ: คำขอโอนย้ายนักเรียน

ทำเสร็จแล้วจะเห็น: คำขอเปลี่ยนเป็น โอนย้ายแล้ว นักเรียนไปอยู่โรงเรียนใหม่ แต่ยังไม่มีรถ โรงเรียนใหม่ต้องจัดรถให้เอง

💡 ถ้าป้ายสถานะขึ้น ต้องตรวจสอบใหม่ แปลว่าข้อมูลนักเรียนเปลี่ยนหลังส่งคำขอ ให้เปิดดูอีกครั้งก่อนอนุมัติ ถ้าขึ้น ยกเลิกแล้ว แปลว่าโรงเรียนถอนคำขอเอง ไม่ต้องทำอะไร

3. อนุมัติคำขอเกี่ยวกับรถ

คำขอมี 4 แบบ: ขอกู้คืนรถ · ขอใช้รถที่มีอยู่ · ขอเพิ่มรถ · ขอตรวจสอบ

  1. เปิดเมนู คำขอเกี่ยวกับรถ
  2. เลือกตัวกรอง รออนุมัติ
  3. กด เปิดดู ที่คำขอ
  4. กด อนุมัติและกู้คืนรถ (คำขอกู้คืน) หรือ อนุมัติคำขอ (แบบอื่น) หรือ ไม่อนุมัติ
  5. พิมพ์ หมายเหตุผู้ดูแล (ต้องกรอก)
  6. กดปุ่มยืนยันอีกครั้ง

ภาพ: คำขอเกี่ยวกับรถ

ทำเสร็จแล้วจะเห็น: คำขอเปลี่ยนเป็น สำเร็จแล้ว มีแค่คำขอกู้คืนรถที่นำรถกลับมาใช้จริง คำขอแบบอื่นเป็นการรับทราบ ไม่ได้แก้ข้อมูลรถ

ถ้าปุ่มอนุมัติกดไม่ได้ (สีจาง) แปลว่ามีรถทะเบียนเดียวกันใช้งานอยู่แล้ว ต้องจัดการรถคันนั้นก่อน

4. ดูแลบัญชีผู้ใช้

เปิดเมนู จัดการผู้ใช้งาน ค้นหาด้วยช่อง ค้นหาชื่อผู้ใช้… หรือกรองด้วย ทุกบทบาท ป้ายสถานะมี 3 แบบ: ใช้งาน (เขียว) · รอเปลี่ยนรหัส (เหลือง) · ระงับ (แดง)

ภาพ: จัดการผู้ใช้งาน

สร้างผู้ใช้ใหม่

  1. กด สร้างผู้ใช้ใหม่
  2. พิมพ์ ชื่อผู้ใช้ และ รหัสผ่าน ชั่วคราว (ตามกฎรหัสผ่านด้านบน)
  3. เลือก บทบาท
  4. ถ้าเป็นโรงเรียน สังกัด หรือจังหวัด ให้เลือก หน่วยงาน
  5. ถ้าเป็นบัญชีครูประจำสายชั้น ให้เลือก ระดับชั้น (สำหรับครูประจำสายชั้น) ถ้าเป็นบัญชีหลักของโรงเรียน ไม่ต้องเลือก
  6. กด สร้างผู้ใช้

ทำเสร็จแล้วจะเห็น: บัญชีใหม่ในตาราง ป้าย รอเปลี่ยนรหัส แจ้งชื่อผู้ใช้และรหัสชั่วคราวให้เจ้าของบัญชีทางช่องทางที่ปลอดภัย

รีเซ็ตรหัสผ่านให้ผู้ใช้

  1. กด รีเซ็ตรหัส ที่แถวของผู้ใช้
  2. พิมพ์รหัสชั่วคราวใหม่
  3. กด รีเซ็ตรหัสผ่าน

ทำเสร็จแล้วจะเห็น: ข้อความ รีเซ็ตรหัสผ่านสำเร็จ ผู้ใช้ต้องตั้งรหัสใหม่ตอนเข้าครั้งถัดไป และเครื่องที่เข้าระบบค้างไว้จะถูกออกจากระบบ

แก้ไข ระงับ หรือลบบัญชี

  1. กด แก้ไข เพื่อเปลี่ยน ชื่อแสดง หรือ สถานะ (ใช้งาน / ระงับ) แล้วกด บันทึก
  2. ถ้าต้องการลบ กด ลบ ตรวจชื่อในกล่อง ลบผู้ใช้ออกจากระบบ? แล้วกด ลบผู้ใช้

💡 ถ้าบัญชีอาจกลับมาใช้อีก ให้ ระงับ แทนการลบ หน้าแก้ไขเปลี่ยนบทบาทหรือหน่วยงานไม่ได้ ถ้าต้องเปลี่ยน ให้สร้างบัญชีใหม่แล้วระงับบัญชีเดิม

5. เปิดดูเรื่องที่ต้องมีส่วนร่วม

เป็นกล่องรวมข้อเสนอ ข้อร้องเรียน และข้อกังวลจากผู้ใช้ทุกบทบาท ผู้ดูแลระบบเห็นทุกเรื่องในจังหวัด ระบบไม่แจ้งเตือนเมื่อมีเรื่องใหม่ ไม่มีอีเมล ไม่มีข้อความ LINE คุณต้องเข้ามาเปิดดูเอง เช่น ทุกเช้าวันทำการ

  1. เปิดหมวด เพิ่มเติม แล้วกด เรื่องที่ต้องมีส่วนร่วม
  2. รายการจะกรอง ที่ยังไม่จบ ไว้ให้ก่อน
  3. กด ดูรายละเอียด ที่เรื่องที่ต้องการ
  4. ที่ส่วน บันทึกเหตุการณ์ใหม่ เลือก เหตุการณ์ แล้วกรอกช่องที่ขึ้นมา
  5. กด บันทึกเหตุการณ์

ลำดับที่ควรทำ: รับเรื่อง → ให้ความเห็นหรือเปิดหารือ → บันทึกมติ → มอบหมายผู้รับผิดชอบ → ดำเนินการเสร็จ → แจ้งผลกลับผู้เสนอ

  • บันทึกมติ ต้องเลือกมติ และกรอก เหตุผลของมติ เสมอ
  • มอบหมายผู้รับผิดชอบ ต้องกรอก รหัสผู้ใช้ที่รับผิดชอบ (เลขประจำบัญชี ไม่ใช่ชื่อ) มอบหมายได้ครั้งเดียว
  • แจ้งผลกลับผู้เสนอ ทำได้หลัง ดำเนินการเสร็จ แล้วเท่านั้น และต้องกรอก สิ่งที่แจ้งกลับผู้เสนอ ขั้นนี้สำคัญที่สุด เพราะเป็นหลักฐานว่าเรื่องได้รับคำตอบ

ถ้าหาเหตุการณ์ที่ต้องการในรายการไม่เจอ แปลว่าเรื่องยังไม่ถึงขั้นนั้น

ภาพ: รายการเรื่องที่ต้องมีส่วนร่วม

ทำเสร็จแล้วจะเห็น: ข้อความ บันทึกเหตุการณ์สำเร็จ และเหตุการณ์ใหม่ต่อท้ายลำดับเหตุการณ์ เมื่อแจ้งผลกลับแล้ว เรื่องจะเป็น ปิดเรื่องแล้ว

⚠️ เหตุการณ์ที่บันทึกแล้วแก้หรือลบไม่ได้ ถ้าพิมพ์ผิด ให้บันทึก ให้ความเห็น อธิบายเพิ่ม ห้ามพิมพ์ชื่อนักเรียน เลขบัตรประชาชน รหัสนักเรียน หรือเบอร์โทร ลงในช่องใด ๆ เพราะหลายบทบาทอ่านได้

งานอื่น ๆ (ทำเมื่อจำเป็น)

แก้ปัญหาข้อมูลคนขับ

ใช้เมื่อคนขับเข้าระบบไม่ได้เพราะบัญชีซ้ำ ต้องย้ายคนขับไปรถคันอื่น หรือต้องปิดบัญชีคนขับ

  1. เปิดเมนู สุขภาพข้อมูลคนขับ ดูการ์ดสรุป เช่น รถที่ยังไม่มีคนขับ หรือ บัญชีซ้ำ/ถูกปิดใช้งาน
  2. กด เครื่องมือจัดการคนขับ
  3. เลือก การดำเนินการ: กู้คืนบัญชีคนขับ / ย้ายคนขับไปรถใหม่ / ปิดใช้งานคนขับ
  4. พิมพ์ รหัสผู้ใช้คนขับ (ถ้าย้ายรถ ให้พิมพ์ รถปลายทาง ด้วย)
  5. กด ตรวจสอบก่อนดำเนินการ แล้วอ่านผลว่าทำได้ ถูกบล็อก หรือมีคำเตือน
  6. พิมพ์ เหตุผล
  7. กด ยืนยันดำเนินการ

ภาพ: สุขภาพข้อมูลคนขับ

ทำเสร็จแล้วจะเห็น: ข้อความ สำเร็จแล้ว และตัวเลขในการ์ดสรุปเปลี่ยนตาม

ถ้ารถปลายทางมีคนขับอยู่แล้ว ต้องติ๊ก ยืนยันสิ้นสุดงานคนขับเดิมของรถคันนี้ ก่อนกดยืนยัน ถ้าระบบบล็อกการกู้คืนเพราะบัญชีซ้ำ ให้ใช้บัญชีหลักของคนขับคนนั้นแทน

ตั้งภาคเรียนปัจจุบัน

ทำเมื่อขึ้นภาคเรียนใหม่ การเช็กชื่อและการนำเข้านักเรียนจะบันทึกในภาคเรียนที่ตั้งไว้

  1. เปิดหมวด ตั้งค่าระบบ แล้วกด ภาคเรียนปัจจุบัน
  2. ถ้ายังไม่มีภาคเรียนที่ต้องการ กด เพิ่มภาคเรียน พิมพ์ รหัสภาคเรียน เช่น 2569-1 แล้วกด บันทึก (ช่องอื่นไม่บังคับ)
  3. กด ตั้งเป็นปัจจุบัน ที่แถวของภาคเรียนนั้น
  4. กด ตั้งเป็นปัจจุบัน ในกล่องยืนยันอีกครั้ง

ทำเสร็จแล้วจะเห็น: ข้อความ ตั้งเป็นภาคเรียนปัจจุบันแล้ว และป้าย ปัจจุบัน ย้ายมาที่แถวนั้น ข้อมูลภาคเรียนเก่าไม่หาย

หน้านี้ไม่มีปุ่มแก้หรือลบภาคเรียน ถ้าพิมพ์รหัสผิด ให้เพิ่มรหัสที่ถูกอีกรายการ แล้วตั้งรายการที่ถูกเป็นปัจจุบัน ถ้าขึ้น โหลดรายการภาคเรียนไม่สำเร็จ อย่าเพิ่งเพิ่มภาคเรียนใหม่ ให้ลองโหลดอีกครั้งก่อน

ดูประวัติการใช้งาน

ใช้ตรวจย้อนหลังว่าใครทำอะไรในระบบ เมื่อไร

  1. เปิดเมนู ประวัติการใช้งาน
  2. เลือกประเภทการกระทำ (ค่าเริ่มต้นคือ ทุกการกระทำ) และช่วงวันที่ ตั้งแต่ – ถึง
  3. เลื่อนดูรายการ ใช้ปุ่ม ก่อนหน้า / ถัดไป เพื่อเปลี่ยนหน้า
  4. ถ้าต้องการไฟล์ กด Export CSV

ภาพ: ประวัติการใช้งาน

ทำเสร็จแล้วจะเห็น: รายการตามตัวกรอง ไฟล์ CSV เปิดใน Excel เป็นภาษาไทยได้ เบอร์โทรและข้อมูลลับจะถูกปิดไว้ทั้งบนจอและในไฟล์

ออกรายงาน

  1. เปิดเมนู รายงาน
  2. เลือกแท็บ รายวัน / รายเดือน / สรุปภาพรวม / เชิงนโยบาย
  3. เลือกวันที่หรือเดือน และตัวกรองอื่นที่ต้องการ
  4. ที่ ดาวน์โหลด: กด CSV, Excel หรือ PDF

ภาพ: หน้ารายงาน

ทำเสร็จแล้วจะเห็น: ไฟล์รายงานทั้งจังหวัดในเครื่องของคุณ ถ้าดาวน์โหลดถี่มาก ระบบอาจให้รอสักครู่

ทำงานแทนโรงเรียน สังกัด จังหวัด หรือขนส่ง

  • จัดการโรงเรียน (หมวด เพิ่มเติม) = หน้าของโรงเรียน เช่น จัดการนักเรียน นำเข้า เช็กชื่อขึ้น-ลงรถ
  • เพิ่มโรงเรียนใหม่ (หมวด เพิ่มเติม) = หน้าของสังกัด เช่น บัญชีโรงเรียน เพิ่มโรงเรียน
  • ภาพรวมจังหวัด · ข้อมูลนักเรียน · รถรับส่ง = ข้อมูลทั้งจังหวัด
  • ตรวจสภาพรถ = หน้าของขนส่ง

หน้าของโรงเรียนและสังกัดจะมีแถบสีเหลืองด้านบน Admin — เลือกโรงเรียน: หรือ Admin — เลือกสังกัด: ต้องเลือกก่อน ข้อมูลจึงจะขึ้น วิธีใช้หน้าอื่น ๆ ดูคู่มือของบทบาทนั้น

ดูหน้าตรวจสอบอื่น ๆ

  • ตรวจสอบจุดรับส่ง = เพิ่มจุดรับส่งกรณีพิเศษด้วยปุ่ม เพิ่มกรณีพิเศษ แก้ หรือลบ (จุดปกติให้คนขับหรือโรงเรียนเพิ่มเอง)
  • ตรวจสอบตำแหน่งรถ = ดูตำแหน่งรถทั้งจังหวัดบนแผนที่ อ่านอย่างเดียว ค้นด้วยทะเบียนหรือชื่อคนขับ ทุกการเปิดดูถูกบันทึกไว้
  • ความพร้อมเปิดใช้งาน = ดูว่ารถและคนขับมีข้อมูลครบหรือยัง และ รายการที่ต้องดำเนินการ พร้อมผู้รับผิดชอบ ให้ประสานหน่วยงานนั้นแก้
  • สุขภาพระบบ = ตัวเลขการใช้งาน 30 วัน เช่น การเข้าสู่ระบบ การเข้าชมเว็บไซต์ ใช้ดูแนวโน้มคร่าว ๆ

ภาพ: ตรวจสอบตำแหน่งรถ

หน้าวิจัยและประเมินผล

หมวด วิจัยและประเมินผล ใช้กับงานประเมินโครงการ

  • กรอบวัดผลระบบ = เอกสารอ่านประกอบ ตัวชี้วัดของแต่ละบทบาท
  • เปรียบเทียบ Baseline = กด Snapshot วันนี้ หรือ สร้าง Baseline เพื่อเก็บค่าไว้เทียบ สร้าง Baseline ซ้ำภายใน 24 ชั่วโมงไม่ได้
  • ส่งออกข้อมูลวิจัย = เลือกช่วงวันที่และชุดข้อมูล ดู ตัวอย่างข้อมูลที่จะส่งออก แล้วดาวน์โหลด JSON / CSV / Excel
  • ประเมินผลแยก Role และ สรุปผู้บริหาร = สรุปความพร้อมของหลักฐานแต่ละบทบาท กด พิมพ์รายงาน เพื่อพิมพ์หรือบันทึกเป็น PDF

⚠️ ตัวเลขในหน้าเหล่านี้คือ ความพร้อมของหลักฐาน ไม่ใช่ผลการวิจัย ถ้าหน้าจอขึ้น ไม่มีข้อมูล ไม่ได้แปลว่า "ไม่มีปัญหา" ถ้าหน้าส่งออกขึ้น ชุดข้อมูลนี้ยังใช้อ้างผลวิจัยไม่ได้ ยังดาวน์โหลดได้ แต่ห้ามนำไปอ้างเป็นผลวิจัย

ภาพ: ประเมินผลแยก Role

ยื่นเรื่องใหม่ และดูสรุปการมีส่วนร่วม

  1. ที่หน้า เรื่องที่ต้องมีส่วนร่วม กด ยื่นเรื่องใหม่
  2. เลือก ประเภทเรื่อง แล้วพิมพ์ หัวเรื่อง และ รายละเอียด
  3. เลือก ขอบเขตของเรื่อง แล้วพิมพ์ รหัสหน่วยงาน เช่น SCH0001 (ขอบเขตจังหวัดไม่ต้องพิมพ์รหัส)
  4. กด ยื่นเรื่อง

ขอบเขตที่เลือกเป็นตัวกำหนดว่าหน่วยงานไหนเห็นเรื่องนี้ ให้เลือกหน่วยงานที่ต้องรับเรื่องไปทำ ค้นในรายการก่อนยื่น เพราะระบบไม่ตรวจเรื่องซ้ำ

เมนู สรุปการมีส่วนร่วม แสดงจำนวนเรื่องทั้งจังหวัด แยกตามสถานะ ประเภท และผู้เสนอ ตัวเลขนี้เป็นการนับงาน ไม่ใช่ผลวิจัย และยังวัดเรื่องเกินกำหนดไม่ได้

ภาพ: สรุปการมีส่วนร่วม

ปัญหาที่พบบ่อย

ถ้าเห็น/ถ้าเกิดให้ทำแบบนี้
ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้องตรวจชื่อผู้ใช้และรหัสผ่านอีกครั้ง บัญชีที่ถูกระงับก็ขึ้นข้อความนี้ ให้เปิดดูสถานะที่หน้า จัดการผู้ใช้งาน
มีการพยายามเข้าสู่ระบบหลายครั้งจากเครือข่ายนี้รอประมาณ 15 นาทีแล้วลองใหม่ บัญชีไม่ได้ถูกปิด
เซสชันหมดอายุจากการเปลี่ยนรหัสผ่านมีการเปลี่ยนหรือรีเซ็ตรหัสของบัญชีนี้ ให้เข้าสู่ระบบใหม่ด้วยรหัสล่าสุด
สร้างผู้ใช้แล้วขึ้น ชื่อผู้ใช้นี้มีอยู่ในระบบแล้วใช้ชื่อผู้ใช้อื่น
สร้างหรือรีเซ็ตแล้วรหัสผ่านไม่ผ่านตั้งรหัสให้ยาว 8 ตัวขึ้นไป ไม่เหมือนชื่อผู้ใช้ ไม่เดาง่าย
เปิดใช้บัญชีคนขับไม่ได้ (ไม่สามารถเปิดใช้งานบัญชีคนขับนี้ได้…)อาจเป็นบัญชีซ้ำ ใช้บัญชีหลักของคนขับ หรือใช้ เครื่องมือจัดการคนขับ
ลบบัญชีแล้วขึ้น ไม่สามารถลบตัวเองได้ระบบไม่ให้ลบบัญชีที่กำลังใช้อยู่ ให้ผู้ดูแลระบบอีกคนทำ
คำขอโอนย้ายขึ้น ไม่สำเร็จมักเป็นรหัสนักเรียนซ้ำที่โรงเรียนปลายทาง ให้โรงเรียนปลายทางแก้ก่อน แล้วส่งคำขอใหม่
กดอนุมัติแล้วเหมือนไม่มีอะไรเกิดขึ้นต้องกรอก หมายเหตุผู้ดูแล แล้วกดปุ่มยืนยันอีกครั้ง
ปุ่ม อนุมัติและกู้คืนรถ กดไม่ได้มีรถทะเบียนเดียวกันใช้งานอยู่ ต้องจัดการรถคันนั้นก่อน
เข้าหน้าโรงเรียนหรือสังกัดแล้วไม่มีข้อมูล หรือขึ้นข้อผิดพลาดเลือกโรงเรียนหรือสังกัดที่แถบสีเหลืองด้านบน
ที่หน้าเรื่องที่ต้องมีส่วนร่วม หาเหตุการณ์ที่ต้องการไม่เจอเรื่องยังไม่ถึงขั้นนั้น ทำขั้นก่อนหน้าให้ครบก่อน
หน้า ศูนย์ควบคุมระบบ ขึ้น โหลดข้อมูลบางส่วนไม่สำเร็จกด รีเฟรช อีกครั้ง

ติดต่อใครเมื่อมีปัญหา

  • ลืมรหัสผ่านและเข้า LINE ไม่ได้ → ให้ผู้ดูแลระบบอีกคนรีเซ็ตรหัสให้
  • ระบบล่ม เปิดเว็บไม่ได้ หรือต้องการเปิดความสามารถใหม่ → ติดต่อผู้ดูแลเซิร์ฟเวอร์
  • ผู้ใช้บทบาทอื่นลืมรหัสผ่าน → คุณรีเซ็ตให้ที่หน้า จัดการผู้ใช้งาน (สังกัดรีเซ็ตบัญชีโรงเรียนในสังกัดได้ด้วย)

สิ่งที่ต้องบอกเมื่อแจ้งปัญหา:

  • ชื่อผู้ใช้ของบัญชีที่มีปัญหา
  • วันและเวลาที่เกิด
  • หน้าหรือเมนูที่ใช้อยู่
  • ภาพหน้าจอที่เห็นข้อความผิดพลาด

งานดูแลเซิร์ฟเวอร์ เช่น ติดตั้งระบบ สำรองข้อมูล ไม่อยู่ในคู่มือนี้ ผู้ดูแลเซิร์ฟเวอร์ดูได้จากคู่มือปฏิบัติการของทีมพัฒนา (OPERATOR_RUNBOOK)

ข้อควรระวังเรื่องข้อมูลนักเรียน

  • ทุกการสร้าง แก้ไข ลบ อนุมัติ และดาวน์โหลด ถูกบันทึกในประวัติการใช้งาน พร้อมชื่อบัญชีของคุณ
  • ดาวน์โหลดไฟล์เท่าที่จำเป็น เก็บในเครื่องของหน่วยงาน ลบเมื่อใช้เสร็จ ห้ามส่งต่อในกลุ่มแชตทั่วไป
  • ห้ามพิมพ์ชื่อนักเรียน เลขบัตรประชาชน หรือเบอร์โทร ลงในช่องหมายเหตุ เหตุผล หรือเรื่องที่ต้องมีส่วนร่วม
  • ห้ามให้คนอื่นใช้บัญชีหรือ LINE ที่ผูกไว้ของคุณ ออกจากระบบทุกครั้งเมื่อใช้เครื่องร่วมกับคนอื่น

ตรวจความเข้าใจหลังอบรม

  • ☐ ผูก LINE ที่ ความปลอดภัยบัญชี แล้ว และรู้วิธีตั้งรหัสใหม่ผ่าน LINE
  • ☐ สร้างผู้ใช้ และรีเซ็ตรหัสให้ผู้ใช้ได้
  • ☐ อนุมัติคำขอโอนย้ายนักเรียนได้ (รวมการกรอกหมายเหตุและกดยืนยัน)
  • ☐ ตั้งภาคเรียนปัจจุบันได้
  • ☐ บันทึกเหตุการณ์ และแจ้งผลกลับผู้เสนอ ในเรื่องที่ต้องมีส่วนร่วมได้

ℹ️ เมนู นโยบายและสิทธิของฉัน ตอนนี้ขึ้นว่า ยังไม่มีประกาศฉบับที่อนุมัติให้ใช้งาน เป็นเรื่องปกติ เมื่อหน่วยงานอนุมัติประกาศแล้วจะแสดงที่หน้านี้
