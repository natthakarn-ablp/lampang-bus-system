คู่มือครูประจำสายชั้น: เช็กชื่อขึ้น-ลงรถ

เว็บไซต์ schoolbuslampang.com · ปรับปรุง 24 ต.ค. 2569 · ภาพในคู่มือเป็นข้อมูลตัวอย่าง ไม่ใช่ข้อมูลจริง

คู่มือนี้สำหรับใคร และทำอะไรได้บ้าง

  • สำหรับครูที่ได้รับบัญชีครูประจำสายชั้นจากโรงเรียน
  • คุณเช็กชื่อเด็กที่ใช้รถรับส่งเฉพาะชั้นที่รับผิดชอบ
  • รอบเช้า บันทึกว่าเด็กถึงโรงเรียนแล้ว
  • รอบเย็น บันทึกว่าเด็กขึ้นรถกลับบ้านแล้ว
  • คุณดูรายชื่อนักเรียน รถรับส่ง และรายงานของชั้นตัวเองได้ แต่แก้ไขไม่ได้
  • ไม่ต้องพิมพ์เหตุผล ระบบจำเองว่าใครกด และกดเวลาไหน

เริ่มต้นใช้งาน

ขอบัญชี

ขอบัญชีจากผู้ดูแลบัญชีของโรงเรียน (เจ้าหน้าที่ที่ใช้บัญชีโรงเรียนหลัก) เขาจะให้ชื่อผู้ใช้และรหัสผ่านเริ่มต้นกับคุณ

เข้าสู่ระบบ

  1. เปิด schoolbuslampang.com บนมือถือ
  2. พิมพ์ชื่อผู้ใช้ในช่อง ชื่อผู้ใช้หรือทะเบียนรถ
  3. พิมพ์รหัสผ่าน
  4. กด เข้าสู่ระบบ

ครั้งแรก ระบบจะขึ้นว่า กรุณาเปลี่ยนรหัสผ่านเริ่มต้น

  1. พิมพ์ รหัสผ่านปัจจุบัน (รหัสที่ได้รับ)
  2. พิมพ์ รหัสผ่านใหม่ อย่างน้อย 8 ตัวอักษร และไม่เดาง่าย
  3. พิมพ์รหัสใหม่อีกครั้งในช่อง ยืนยันรหัสผ่านใหม่
  4. กด เปลี่ยนรหัสผ่าน

ลืมรหัสผ่าน

แจ้งผู้ดูแลบัญชีของโรงเรียน ให้ตั้งรหัสใหม่ให้ (เมนู เพิ่มเติม › บัญชีครูประจำสายชั้น › รีเซ็ตรหัส)

💡 เคล็ดลับ: บันทึกหน้าเว็บไว้ที่หน้าจอหลักของมือถือ จะเปิดได้เร็วเหมือนแอป

งานประจำวัน (ทำตามลำดับ)

  1. เปิดหน้า เช็กชื่อวันนี้
  2. ตรวจว่าเลือกรอบถูก (เช้า หรือ เย็น)
  3. เห็นเด็กแล้ว แตะชื่อเด็ก
  4. ดูว่าปุ่ม ยังไม่เช็ก เหลือ 0 คน

1. เปิดหน้าเช็กชื่อ

เลือกทางใดทางหนึ่ง

  • มือถือ: แตะ เช็กชื่อ ที่แถบด้านล่างของจอ
  • หน้าแรก: กดปุ่มสีเขียว เช็กชื่อวันนี้
  • เมนูด้านข้าง: กด เช็กชื่อวันนี้

ด้านบนของจอจะเห็นป้าย ขอบเขตข้อมูล ตามด้วยชั้นของคุณ เช่น ป.1

ภาพ: หน้าแรกของครูประจำสายชั้น ปุ่มสีเขียวอยู่ด้านบน (ภาพนี้ยังเป็นชื่อปุ่มเดิม "เช็กชื่อขึ้น-ลงรถ" บนจอจริงคือ "เช็กชื่อวันนี้")

2. เลือกรอบ

ด้านบนมีปุ่ม 2 ปุ่ม: เช้า · ถึงโรงเรียน และ เย็น · ขึ้นรถกลับบ้าน

  • ก่อนเที่ยง ระบบเลือกรอบเช้าให้เอง
  • หลังเที่ยง ระบบเลือกรอบเย็นให้เอง
  • ถ้าต้องการอีกรอบ กดปุ่มรอบนั้น

ใต้ปุ่มรอบจะบอก บันทึกแล้ว … จาก … คน และเปอร์เซ็นต์ของชั้นคุณ

3. แตะชื่อเด็กเมื่อเห็นตัวจริง

รายชื่อแยกเป็นกล่องตามคันรถ หัวกล่องบอกทะเบียนรถ และ บันทึกแล้ว … / … คน

  1. รอบเช้า: เมื่อเห็นเด็กลงจากรถที่โรงเรียน แตะชื่อเด็ก
  2. รอบเย็น: เมื่อเห็นเด็กขึ้นรถ แตะชื่อเด็ก
  3. รอให้ขึ้นข้อความ บันทึกแล้ว 1 คน

แตะครั้งเดียวก็บันทึกแล้ว ไม่ต้องกดปุ่มบันทึกอีก

ทำเสร็จแล้วจะเห็น: วงกลมหน้าชื่อเป็นเครื่องหมายถูกสีเขียว และป้าย "ถึงโรงเรียนแล้ว 07:42 น. · คุณ" (รอบเย็นเป็น "ขึ้นรถแล้ว … · คุณ")

ภาพ: หน้าเช็กชื่อบนมือถือ (ภาพนี้ยังเป็นหัวข้อและชื่อปุ่มแบบเดิม)

ค้นหาเด็ก หรือดูทั้งหมด

  • ปกติจอแสดงเฉพาะเด็กที่ ยังไม่เช็ก เด็กที่บันทึกแล้วจะหายจากรายการ
  • อยากเห็นทุกคน (รวมคนที่บันทึกแล้ว ลา หรือไม่มีรถ) กด ทั้งหมด
  • หาเด็กไม่เจอ พิมพ์ชื่อ ชั้น ห้อง หรือทะเบียนรถ ในช่อง ค้นหานักเรียนหรือรถ

บันทึกทั้งคันในครั้งเดียว

ใช้เมื่อเห็นเด็กที่เหลือในคันนั้นครบทุกคนจริง

  1. ล้างช่องค้นหาให้ว่างก่อน (ขณะค้นหา ปุ่มนี้จะไม่แสดง)
  2. กดปุ่มสีเขียว บันทึกที่เหลือทั้งคัน (… คน) ที่หัวกล่องของรถคันนั้น
  3. อ่านจำนวนคนในหน้าต่างที่ขึ้นมา
  4. กด ยืนยัน … คน

ทำเสร็จแล้วจะเห็น: ข้อความ บันทึกแล้ว … คน และหัวกล่องบอกว่าบันทึกครบ

ภาพ: ระบบถามยืนยันก่อนบันทึกทั้งคัน (บนจอจริงปุ่มยืนยันบอกจำนวนคน เช่น "ยืนยัน 1 คน")

⚠️ ระวัง: ถ้าไม่แน่ใจว่ามีเด็กไม่มา ให้แตะทีละชื่อ อย่ากดทั้งคัน ระบบข้ามเด็กที่ลาและเด็กที่บันทึกแล้วให้เอง

อ่านป้ายข้างชื่อเด็ก

ถ้าเห็นให้ทำแบบนี้
วงกลมว่าง ไม่มีป้ายยังไม่มีใครบันทึก แตะชื่อเมื่อเห็นเด็ก
✅ "… · คุณ"คุณบันทึกแล้ว ไม่ต้องทำอะไร
✅ "… · คนขับ" หรือ "… · ชื่อครูท่านอื่น"มีคนบันทึกแล้ว ไม่ต้องเช็กซ้ำ
ℹ️ คนขับรับขึ้นรถแล้ว (รอบเช้า)คนขับรับเด็กจากบ้านแล้ว แต่ยังไม่มีใครยืนยันว่าถึงโรงเรียน เมื่อเห็นเด็กถึงโรงเรียน ให้แตะชื่อตามปกติ
✅ ส่งถึงบ้านแล้ว (รอบเย็น)คนขับส่งเด็กแล้ว ไม่ต้องทำอะไร
ชื่อมีเส้นขีดฆ่า + ป้าย ลาเด็กลารอบนี้ แตะไม่ได้ ไม่ต้องบันทึก
ป้าย ไม่มีรถ ในกล่อง ยังไม่ได้ผูกรถเด็กยังไม่มีรถในระบบ แจ้งผู้ดูแลบัญชีของโรงเรียนให้เลือกรถให้เด็ก

กดผิด ยกเลิกอย่างไร

  1. กด ทั้งหมด เพื่อให้เห็นแถวที่บันทึกแล้ว
  2. หาแถวที่กดผิด
  3. กด ยกเลิก ด้านขวาของชื่อ

ทำเสร็จแล้วจะเห็น: ข้อความ "ยกเลิกรายการของ … แล้ว" และวงกลมหน้าชื่อกลับเป็นว่าง

  • ยกเลิกได้เฉพาะรายการที่คุณบันทึกเอง และเป็นรายการของวันนี้
  • รายการของคนขับหรือครูท่านอื่นไม่มีปุ่ม ยกเลิก ให้คนที่บันทึกยกเลิกเอง หรือแจ้งผู้ดูแลบัญชีของโรงเรียน
  • ถ้าคนขับบันทึกไว้ก่อน (เช่น รับขึ้นรถแล้ว) เมื่อคุณยกเลิกรายการของคุณ รายการของคนขับยังอยู่

งานอื่น ๆ (ทำเมื่อจำเป็น)

ดูรถรับส่งของชั้นคุณ

  1. กดเมนู รถรับส่ง
  2. ดูรถที่เด็กในชั้นคุณใช้ พร้อมคนขับและรายชื่อเด็กในคัน

คุณเห็นเฉพาะรถที่มีเด็กในชั้นคุณ และแก้ไขข้อมูลรถไม่ได้ (ไม่มีปุ่มแก้ไขหรือเพิ่มรถ) ถ้าข้อมูลรถผิด แจ้งผู้ดูแลบัญชีของโรงเรียน

ดูรายชื่อนักเรียน และรายงาน

  • กด นักเรียน เพื่อดูรายชื่อเด็กในชั้นคุณ (ดูได้อย่างเดียว)

  • รอบเย็นที่คุณบันทึก ผู้ปกครองเห็น ขึ้นรถกลับบ้านแล้ว

ถ้าเห็น/ถ้าเกิดให้ทำแบบนี้

ขึ้นว่า "ข้าม … คน (ลา / ไม่ได้ใช้รถรอบนี้)"เด็กลา หรือไม่ได้ใช้รถรอบนี้ ไม่ต้องทำอะไร
