# คู่มือสังกัด/เขต (Affiliation)

## ขอบเขตสิทธิ์

สังกัดเห็นข้อมูลเฉพาะโรงเรียนในสังกัดของตน ใช้ติดตามผลการดำเนินงาน สร้าง/นำเข้าบัญชีโรงเรียน และดูรายงานในขอบเขตสังกัด

## เมนูหลัก

| เมนู | งาน |
|---|---|
| ภาพรวมสังกัด | KPI และสถานะโรงเรียนในสังกัด |
| โรงเรียนในสังกัด | รายชื่อโรงเรียน |
| ข้อมูลนักเรียน | ค้นหานักเรียนในสังกัด |
| รถรับส่ง | ดูรถในสังกัด |
| จัดการบัญชีโรงเรียน | เพิ่มโรงเรียน/นำเข้า school accounts |
| สถานะวันนี้ | ติดตามเช็กชื่อ |
| ตำแหน่งปัจจุบัน | ดู live vehicles |
| แผนที่จุดรับส่ง | ดู pickup map |
| เหตุฉุกเฉิน | ดูเหตุในสังกัด |
| Audit log | ตรวจย้อนหลัง |

## 3. จัดการบัญชีโรงเรียน

ใช้เพิ่มบัญชีโรงเรียนใหม่ หรือนำเข้าหลายโรงเรียนจากไฟล์ Excel ตาม template

1. เปิดเมนู "จัดการบัญชีโรงเรียน"
2. เลือกเพิ่มรายโรงเรียน หรือดาวน์โหลด template สำหรับนำเข้า
3. ตรวจ preview ก่อน commit
4. หลังสร้างบัญชี ให้แจ้งโรงเรียนเปลี่ยนรหัสครั้งแรก

![จัดการบัญชีโรงเรียน](../manual-html/screenshots/affiliation/05-accounts.png)

ภาพประกอบ: หน้าจัดการบัญชีโรงเรียน

ข้อควรระวัง:
- ตรวจ school code และชื่อโรงเรียนก่อน commit
- ห้ามใส่รหัสผ่านจริงในไฟล์ที่ส่งต่อ
- หากต้องแก้โรงเรียนที่มีข้อมูลจริง ให้ประสานผู้ดูแลระบบก่อน

## ตรวจรับหลังอบรม Affiliation

| ข้อ | งานทดสอบ | ผลที่ต้องได้ |
|---|---|---|
| 1 | เปิด dashboard | เห็นข้อมูลเฉพาะสังกัด |
| 2 | ค้นหาโรงเรียน | เห็นเฉพาะโรงเรียนในสังกัด |
