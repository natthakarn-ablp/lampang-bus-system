# คู่มือโรงเรียนเต็มสิทธิ์ (School Full)

ปรับปรุงล่าสุด 6 กันยายน 2569 (ตรวจกับระบบจริง commit 14caf5b)

## ขอบเขตสิทธิ์

โรงเรียนเต็มสิทธิ์ใช้ดูแลข้อมูลนักเรียน รถ คนขับ ผู้ปกครอง จุดรับส่ง รายงาน และบัญชีครูประจำสายชั้นในโรงเรียนของตน

## เมนูหลัก

แถบเมนูด้านข้างจัดเมนูเป็น 5 กลุ่ม ตามคอลัมน์ "กลุ่มเมนู" ในตารางนี้

| กลุ่มเมนู | เมนู | งาน |
|---|---|---|
| ภาพรวม | ภาพรวมโรงเรียน | KPI และสถานะวันนี้ |
| งานดำเนินการ | คำขอรายชื่อ | อนุมัติ/ปฏิเสธคำขอจากคนขับ |
| งานดำเนินการ | ตรวจลงทะเบียนรถ | ตรวจรายชื่อเด็กที่คนขับส่งมา และตรวจเอกสารรถ/คนขับ แล้วอนุมัติ |
| งานดำเนินการ | ส่งตรวจและรับรองรถ | ออกใบส่งตรวจให้ขนส่ง และติดตามสถานะ |
| ข้อมูลหลัก | ข้อมูลนักเรียน | ค้นหา เพิ่ม แก้ไข นำเข้า ส่งออก |
| ข้อมูลหลัก | รถรับส่ง | ดูรถ คนขับ และรายชื่อนักเรียนในรถ แก้ไขข้อมูลรถได้ |
| ข้อมูลหลัก | เพิ่มรถรับส่ง | เพิ่มรถใหม่ได้สูงสุด 10 คันต่อครั้ง |
| ข้อมูลหลัก | บัญชีครูประจำสายชั้น | สร้างบัญชีจำกัดระดับชั้น |
| ตรวจสอบและสนับสนุน | แผนที่จุดรับส่ง | จัดจุดรับส่งและผูกนักเรียน |
| ตรวจสอบและสนับสนุน | ตำแหน่งปัจจุบัน | ดูตำแหน่งรถของโรงเรียน |
| ตรวจสอบและสนับสนุน | เหตุฉุกเฉิน | ดูเหตุของโรงเรียน |
| ตรวจสอบและสนับสนุน | ประวัติการแก้ไข | ตรวจย้อนหลังว่าใครแก้ข้อมูลอะไร (audit log) |
| รายงานและวิจัย | รายงาน | รายวัน รายเดือน สรุปภาพรวม |

> เมนู "ตรวจลงทะเบียนรถ" แสดงอยู่จริงในแถบด้านข้าง เพราะฟีเจอร์นี้เปิดใช้งานแล้วบนระบบจริง (feature flag `FEATURE_DRIVER_REGISTRATION` — ตรวจสถานะเมื่อ 6 ก.ย. 2569)
> ส่วนเมนู "เรื่องที่ต้องมีส่วนร่วม" **ยังไม่เปิดใช้งาน** จึงยังไม่แสดงในแถบด้านข้าง

## 3. Import ข้อมูล

1. กดปุ่ม "ดาวน์โหลดตัวอย่าง" ที่หน้า "ข้อมูลนักเรียน" จะได้ไฟล์แบบฟอร์ม "แบบฟอร์มนำเข้านักเรียน.csv"
2. กรอกข้อมูลตามคอลัมน์ที่กำหนด แล้วบันทึกเป็น .csv หรือ .xlsx (หน้าจอเขียนว่ารองรับ .xls ด้วย แต่ไฟล์ .xls รุ่นเก่าจะถูกปฏิเสธพร้อมข้อความ "ไฟล์ .xls (รุ่นเก่า) ไม่รองรับ กรุณาบันทึกเป็น .xlsx หรือ .csv")
3. กดปุ่ม "นำเข้าข้อมูล" ระบบจะเปิดหน้าต่าง "ตรวจสอบไฟล์ก่อนนำเข้า" ดูแถบ "ภาคเรียนที่จะบันทึก" เพื่อทราบว่าข้อมูลชุดนี้จะถูกบันทึกเป็นภาคเรียนใด (ระบบกำหนดจากวันที่นำเข้าโดยอัตโนมัติ แก้เองไม่ได้) แล้วเลือกไฟล์
4. ถ้าต้องการให้ระบบสร้างรถให้เองสำหรับทะเบียนใหม่ที่ระบุจังหวัดครบถ้วน ให้ติ๊ก "สร้างรถอัตโนมัติสำหรับทะเบียนใหม่ที่มีจังหวัดครบถ้วน โดยบันทึกเป็นรถรอตรวจสอบ" (ถ้าไม่ติ๊ก แถวที่ไม่พบทะเบียนรถในระบบจะนำเข้าไม่ได้)
5. กด "ตรวจสอบไฟล์ก่อนนำเข้า" ขั้นนี้เป็นการตรวจสอบเท่านั้น ระบบยังไม่บันทึกข้อมูลนักเรียน
6. ตรวจการ์ดสรุป (ทั้งหมด / พร้อมนำเข้า / ซ้ำในโรงเรียน / คำเตือน / ข้อผิดพลาด / รถมีปัญหา) และติ๊กยืนยันรายแถวสำหรับรายการที่ต้องตัดสินใจ คือ "อัปเดตผู้ปกครอง" และ "กู้คืนนักเรียน"
7. กด "ยืนยันนำเข้า" เมื่อมั่นใจว่าผลตรวจถูกต้อง แล้วยืนยันอีกครั้งในหน้าต่าง "ยืนยันการนำเข้า"

## ตรวจรับหลังอบรม School Full

| ข้อ | งานทดสอบ | ผลที่ต้องได้ |
|---|---|---|
| 1 | เปิด dashboard | เห็น KPI โรงเรียน |
| 2 | ค้นหานักเรียน | เห็นเฉพาะนักเรียนโรงเรียนตน |
| 3 | เปิด import preview | ตรวจไฟล์ก่อน commit ได้ |
| 4 | เปิดแผนที่จุดรับส่ง | เห็นข้อมูลโรงเรียนตน |
| 5 | สร้างบัญชีครูสายชั้น | บัญชีถูกจำกัดระดับชั้น |
| 6 | เปิดรายงาน | ดู/ส่งออกตามสิทธิ์ได้ |
