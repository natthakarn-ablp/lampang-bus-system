# สังกัด/เขต รีเซ็ตรหัสผ่านให้โรงเรียนได้เอง — ไม่ต้องรอผู้ดูแลระบบ

> เอกสารแจ้งสำนักงานเขตพื้นที่การศึกษาทั้ง 6 แห่งในจังหวัดลำปาง · จัดทำ 7 กันยายน 2569
> ทุกชื่อเมนู ชื่อปุ่ม และข้อความในเอกสารนี้คัดจากหน้าจอจริงของระบบ ไม่ได้เขียนขึ้นเอง

## เรื่องนี้สำคัญอย่างไร

โรงเรียนลืมรหัสผ่านบ่อยที่สุดในบรรดาผู้ใช้ทุกกลุ่ม ที่ผ่านมาเรื่องเหล่านี้ถูกส่งไปที่ผู้ดูแลระบบส่วนกลางเพียงคนเดียว ทำให้โรงเรียนต้องรอ

**ความจริงคือสังกัดทำเองได้อยู่แล้ว** ระบบเปิดสิทธิ์นี้ให้สังกัดมาตั้งแต่ต้น เพียงแต่ยังไม่ได้แจ้งให้ทราบ ตั้งแต่วันนี้ขอให้โรงเรียนติดต่อสังกัดของตนเองก่อนเสมอ

## สังกัดรีเซ็ตให้ใครได้บ้าง

| รีเซ็ตได้ | รีเซ็ตไม่ได้ |
|---|---|
| บัญชีโรงเรียน **ที่อยู่ในสังกัดของท่านเท่านั้น** | โรงเรียนในสังกัดอื่น (ระบบไม่แสดงให้เห็นด้วยซ้ำ) |
| | บัญชีครูประจำสายชั้น — **โรงเรียนรีเซ็ตให้ครูของตนเองได้** ที่เมนู "บัญชีครูประจำสายชั้น" |
| | บัญชีคนขับ — ให้โรงเรียนแจ้งผู้ดูแลระบบ |
| | บัญชีสังกัดของท่านเอง — **จังหวัดรีเซ็ตให้ได้แล้ว** ตั้งแต่ 7 ก.ย. 2569 |

## ขั้นตอน 5 ขั้น

1. เข้าสู่ระบบด้วยบัญชีสังกัดที่ `https://schoolbuslampang.com`
2. ที่แถบเมนูด้านซ้าย เลือก **"เพิ่มโรงเรียนใหม่"**
   *(ชื่อเมนูอ่านแล้วอาจสับสน เพราะหน้านี้รวมทั้งการเพิ่มโรงเรียนใหม่และการจัดการบัญชีโรงเรียนที่มีอยู่ไว้ด้วยกัน)*
3. เลื่อนลงไปที่ตารางรายชื่อบัญชีโรงเรียน หาโรงเรียนที่ต้องการ
4. กดปุ่ม **"รีเซ็ตรหัส"** ในแถวของโรงเรียนนั้น
5. กรอก **"รหัสผ่านใหม่"** และ **"ยืนยันรหัสผ่านใหม่"** ให้ตรงกัน แล้วกด **"รีเซ็ตรหัสผ่าน"**

เมื่อสำเร็จจะขึ้นข้อความว่า *"รีเซ็ตรหัสผ่านสำเร็จ — ผู้ใช้ต้องเปลี่ยนรหัสเมื่อเข้าสู่ระบบครั้งถัดไป"*

## กติกาของรหัสผ่านที่ตั้งให้

- อย่างน้อย **8 ตัวอักษร** และไม่เกิน 128 ตัวอักษร
- **ห้ามตรงกับชื่อผู้ใช้** ของบัญชีนั้น
- ห้ามใช้รหัสที่เดาง่าย ระบบปฏิเสธคำเหล่านี้ตรง ๆ เช่น `12345678`, `123456789`, `password`, `00000000`, `11111111`, `qwertyui`, `abc12345`, `iloveyou`
- ห้ามใช้ตัวอักษรตัวเดียวซ้ำกันทั้งหมด เช่น `aaaaaaaa`

ถ้ารหัสไม่ผ่านกติกา ระบบจะขึ้นข้อความบอกเหตุผล เช่น *"รหัสผ่านนี้คาดเดาง่ายเกินไป กรุณาใช้รหัสผ่านอื่น"* หรือ *"รหัสผ่านต้องไม่ตรงกับชื่อผู้ใช้"*

## สิ่งที่เกิดขึ้นหลังกดรีเซ็ต

- โรงเรียนเข้าสู่ระบบด้วยรหัสที่ท่านตั้งให้ แล้ว **ระบบจะบังคับให้ตั้งรหัสใหม่ทันที** ก่อนใช้เมนูอื่นได้
- **การเข้าใช้งานเดิมที่ค้างอยู่จะถูกตัดออกทันที** ถ้ามีใครยังเปิดหน้าเว็บค้างไว้ด้วยรหัสเดิม จะใช้งานต่อไม่ได้
- ระบบบันทึกไว้ว่า **ใครรีเซ็ตให้ใคร เมื่อไร** ดูย้อนหลังได้ที่เมนู "ประวัติการแก้ไข"

## ข้อควรระวัง

**ส่งรหัสชั่วคราวให้ถูกคน** โทรแจ้งผู้อำนวยการหรือผู้รับผิดชอบบัญชีของโรงเรียนโดยตรง อย่าส่งในกลุ่มไลน์รวม เพราะบัญชีโรงเรียนเห็นรายชื่อนักเรียนทั้งโรงเรียน

**อย่าใช้รหัสเดียวกันกับทุกโรงเรียน** ตั้งรหัสต่างกันในแต่ละครั้ง เพราะรหัสที่ใช้ซ้ำจะถูกเดาได้ง่ายเมื่อรั่วเพียงที่เดียว

**ถ้าผู้ถือบัญชีของโรงเรียนย้ายหรือลาออก** ให้รีเซ็ตรหัสผ่านทันทีในวันที่ส่งมอบงาน อย่ารอให้ผู้รับช่วงร้องขอ

**ถ้ากรอกรหัสผิดหลายครั้ง** ระบบจะระงับการเข้าสู่ระบบชั่วคราว เมื่อกรอกผิด 10 ครั้งสำหรับชื่อผู้ใช้เดียวกันจากเครือข่ายเดียวกัน หรือ 20 ครั้งจากเครือข่ายเดียวกันภายใน 15 นาที กรณีนี้ให้รอ 15 นาทีแล้วลองใหม่ ไม่ต้องรีเซ็ตรหัส

## ถ้าโรงเรียนติดต่อผู้ดูแลระบบโดยตรง

ขอให้แจ้งกลับว่า **ให้ติดต่อสังกัดของตนเองก่อน** ผู้ดูแลระบบยังรีเซ็ตให้ได้ แต่ควรเป็นทางสุดท้ายเมื่อสังกัดติดต่อไม่ได้จริง ๆ เพื่อให้แต่ละระดับดูแลกันเองได้และไม่ต้องรอคนกลางคนเดียว

## สรุปว่าใครดูแลใคร

```
จังหวัด        →  รีเซ็ตให้  สังกัด และ ขนส่ง
สังกัด/เขต     →  รีเซ็ตให้  โรงเรียนในสังกัดตนเอง
โรงเรียน       →  รีเซ็ตให้  ครูประจำสายชั้นของตนเอง
ผู้ดูแลระบบ    →  รีเซ็ตให้  ทุกบทบาท (ใช้เป็นทางสุดท้าย)
```

## ติดปัญหา

หากกดปุ่มแล้วขึ้นข้อความผิดพลาด ให้บันทึกภาพหน้าจอพร้อมข้อความที่ขึ้น แล้วแจ้งผู้ดูแลระบบ ระบุชื่อโรงเรียน เวลาที่ทำ และสิ่งที่กด เพื่อให้ตรวจสอบย้อนหลังจากบันทึกของระบบได้
