# ชุดคู่มือการใช้งานพร้อมภาพประกอบ แยกตามสิทธิ์

ระบบอุ่นใจไปโรงเรียน (School Safe Connect)  
ระบบรถรับส่งนักเรียนจังหวัดลำปาง: https://schoolbuslampang.com  
อัปเดตเอกสาร: 26 สิงหาคม 2569

## วัตถุประสงค์

ชุดเอกสารนี้จัดทำเพื่อใช้ในการอบรมหน่วยงานจังหวัด สังกัด โรงเรียน คนขับ ผู้ปกครอง และผู้ดูแลระบบ โดยแยกคู่มือออกตามสิทธิ์การใช้งานจริงของระบบ พร้อมภาพประกอบหน้าจอและ checklist ตรวจรับงานหลังอบรม

ภาพประกอบทั้งหมดอ้างอิงจากชุดภาพใน `docs/manual-html/screenshots/` ซึ่งเป็นภาพที่เตรียมไว้สำหรับคู่มือระบบและหลีกเลี่ยงการเปิดเผยข้อมูลส่วนบุคคลของนักเรียน/ผู้ปกครอง

## วิธีใช้ชุดคู่มือ

1. เริ่มจากอ่านไฟล์ `00-shared-login-and-security.md` สำหรับขั้นตอนร่วมทุกสิทธิ์
2. แจกคู่มือเฉพาะสิทธิ์ให้ผู้เข้าอบรมตามบทบาทของตน
3. ใช้หัวข้อ "ตรวจรับหลังอบรม" ท้ายแต่ละไฟล์เป็นรายการ UAT แบบง่าย
4. ห้ามใส่รหัสผ่านจริง, token, LINE user id, เลขบัตรประชาชน, เบอร์โทรเต็ม หรือรายชื่อนักเรียนดิบลงในหลักฐานอบรม

## สิ่งที่ต้องย้ำระหว่างอบรม

| เรื่อง | แนวปฏิบัติ |
|---|---|
| ข้อมูลเด็ก | เปิดดูเท่าที่จำเป็น ห้ามส่งต่อภาพหน้าจอที่มีข้อมูลส่วนบุคคล |
| รหัสผ่าน | ห้ามบอกรหัสผ่านในกลุ่มไลน์หรือเอกสารอบรม |
| สิทธิ์ผู้ใช้ | ใช้บัญชีของตนเอง ห้ามใช้บัญชีร่วมกัน |
| รายงาน | ส่งออกเฉพาะผู้มีหน้าที่ และเก็บไฟล์ตามระเบียบหน่วยงาน |
| เหตุฉุกเฉิน | คนขับบันทึกเหตุทันที โรงเรียน/สังกัด/จังหวัดใช้หน้ารายการเพื่อติดตาม |
| LINE OA | ผู้ปกครองต้องผูกบัญชีด้วยข้อมูลที่โรงเรียนบันทึกไว้เท่านั้น |

## ภาพรวมการแบ่งสิทธิ์

| สิทธิ์ | ขอบเขตข้อมูล | งานหลัก | ลักษณะการใช้งาน |
|---|---|---|---|
| Admin | ทั้งระบบ | บัญชีผู้ใช้, audit log, คำขอ, health, readiness | จัดการและตรวจสอบ |
| Province | ทั้งจังหวัด | dashboard, live map, รายงาน, audit log | อ่านและวิเคราะห์ |
| Affiliation | เฉพาะสังกัด | ติดตามโรงเรียน, จัดการบัญชีโรงเรียน, รายงาน | กำกับดูแล |
| School full | เฉพาะโรงเรียน | นักเรียน, รถ, import, ครูสายชั้น, รายงาน | ปฏิบัติงานหลัก |
| School teacher | เฉพาะชั้นที่ได้รับมอบหมาย | ดูข้อมูล/ติดตามนักเรียนในชั้น | อ่านแบบจำกัด |
| Driver | รถ/รอบของตน | ตรวจรถ, เช็กชื่อ, แจ้งเหตุ, ส่งตำแหน่ง | มือถือหน้างาน |
| Transport | รถและการตรวจรับรอง | ตรวจสภาพ, คิวรับรอง, รายการรถ | ตรวจสอบมาตรฐาน |
| Parent/LINE | บุตรหลานของตน | ผูกบัญชี, ดูสถานะ, รับแจ้งเตือน | LINE/LIFF |
