# แจ้งเตือน LINE เมื่อ GPS รถค้างจุดเดิมหรือหยุดส่ง (GPS stale alert)

ที่มา: เจ้าของระบบขอเมื่อ 2026-11-12 ว่า "GPS ถ้าค้างจุดเดิมนานเกิน 20 นาทีให้แจ้งเตือนผ่านไลน์" และตัดสินว่า
ส่งเข้า **กลุ่ม LINE แจ้งเหตุเดิม** (`LINE_GROUP_ID`) และแจ้ง **ทั้งสองกรณี**: ค้างจุดเดิม และไม่ได้รับตำแหน่ง

## ทำงานอย่างไร

`backend/scripts/gps-stale-alert.js` (cron ทุก 5 นาที) → `backend/src/services/gpsStaleAlert.service.js`

1. ทำงานเฉพาะในช่วงติดตาม GPS (`GPS_TRACKING_WINDOWS`, ค่าเริ่มต้น 05:00–09:00, 15:00–19:00 น.)
2. หา **รอบที่ยังไม่จบ**: รถที่มีนักเรียนซึ่งรายการล่าสุดของรอบนี้ใน `checkin_logs` เป็น `CHECKED_IN`
   (ขึ้นรถแล้ว ยังไม่บันทึกส่ง) — กด "จบรอบ" (checkout-all), ครูบันทึกถึงโรงเรียน หรือยกเลิกรายการ จะทำให้รถหลุดจากการตรวจ
3. ดูตำแหน่งใน `vehicle_location_history` ของรอบนั้น
   - **STUCK** — ยังได้รับตำแหน่ง แต่ทุกจุดใน 20 นาทีล่าสุดอยู่ในรัศมี 75 ม. จากจุดล่าสุด
   - **NO_SIGNAL** — รอบนี้เคยส่งตำแหน่ง แต่ไม่ได้รับเลยเกิน 20 นาที
   - รถที่ไม่ได้เปิดส่งตำแหน่งเลยในรอบนั้น → ไม่แจ้ง
   - รอบเย็น: ถ้ารถยังไม่ขยับจากจุดที่นักเรียนขึ้นรถ (รอที่โรงเรียน) → ไม่แจ้ง STUCK
   - ตัดสินจากระยะทางระหว่างพิกัด ไม่ใช้ค่า speed ของมือถือ
4. ส่งข้อความเข้ากลุ่มด้วย `line.service.pushToEmergencyGroup` — ทะเบียนรถ รอบ จำนวนนักเรียนบนรถ ชื่อโรงเรียน
   เวลา + ลิงก์แผนที่ของตำแหน่งล่าสุด **ไม่มีชื่อนักเรียน** และ **ไม่ส่งถึงผู้ปกครอง**
5. แจ้ง **ไม่เกิน 1 ครั้งต่อ รถ + วัน + รอบ + ชนิด** — กันซ้ำด้วยแถวใน `audit_logs`
   (`action='ROUTE_DEVIATION'`, `entity_type='gps_stale_alert'`, `entity_id='<vehicle>:<YYYY-MM-DD>:<M|E>:<kind>'`)
   ไม่ต้องมี migration ใหม่ ถ้าส่งไม่สำเร็จจะไม่บันทึก แล้วลองใหม่รอบถัดไป

ไม่เกี่ยวกับตัวตรวจ STALLED เดิมใน `routeDeviation.service.js` (ผูกกับกะ `vehicle_operating_shifts` และค่า speed) ซึ่งยังปิดอยู่

## ค่าที่ตั้งได้ (backend/.env)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `FEATURE_GPS_STALE_ALERT` | ปิด | ต้องเป็น `true` สคริปต์จึงจะส่งจริง (`--apply`) |
| `GPS_STALE_ALERT_MINUTES` | 20 (ต่ำสุด 5) | นาทีที่ค้าง / ไม่ได้รับตำแหน่ง |
| `GPS_STALE_RADIUS_M` | 75 (ต่ำสุด 20) | รัศมีที่ถือว่า "จุดเดิม" |
| `LINE_GROUP_ID` | — | กลุ่มปลายทาง (ใช้ร่วมกับเหตุฉุกเฉิน) ถ้าไม่ตั้ง ระบบข้ามการส่งและไม่บันทึกว่าแจ้งแล้ว |

## เปิดใช้บน production (เจ้าของทำ หรืออนุมัติให้ทำ)

1. deploy โค้ดตามปกติ
2. ทดลองแบบไม่ส่ง (ช่วงมีรถวิ่ง):
   `cd /home/schoolbus/apps/lampang-bus-system && node backend/scripts/gps-stale-alert.js`
   — แสดงรถที่ตรวจ ข้อความที่ "จะส่ง" และเหตุผลที่ข้าม ไม่ส่งและไม่เขียนอะไร
3. เปิด flag: `bash scripts/enable-feature-flag.sh FEATURE_GPS_STALE_ALERT true` (สำรอง .env ให้เอง) แล้วอัปเดต `scripts/production-feature-flags.json`
4. เพิ่ม cron (เครื่องเป็น UTC แต่สคริปต์ตรวจช่วงเวลาไทยเอง จึงรันทุก 5 นาทีได้):
   `*/5 * * * * cd /home/schoolbus/apps/lampang-bus-system && node backend/scripts/gps-stale-alert.js --apply >> /home/schoolbus/logs/gps-stale-alert.log 2>&1`
5. ปิด: ลบบรรทัด cron หรือตั้ง flag เป็น false

## โควตา LINE

LINE OA แบบฟรีส่งได้ประมาณ 500 ข้อความ/เดือน และข้อความเข้ากลุ่มอาจนับตามจำนวนสมาชิกกลุ่ม ตรวจแพ็กเกจก่อนเปิดใช้
ระบบจำกัดไว้ที่ไม่เกิน 2 ข้อความ (STUCK + NO_SIGNAL) ต่อรถต่อรอบ
