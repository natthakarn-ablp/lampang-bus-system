# รถวิ่งหลายเที่ยวต่อรอบ (multi-trip)

ที่มา: เจ้าของระบบ 2026-11-12 "เพิ่มข้อมูลเหตุเรื่อง รับนักเรียนหลายรอบ" → หมายถึง **รถคันเดียววิ่งหลายเที่ยวในรอบเดียว** และตัดสินว่า
- **คนขับกดเริ่มเที่ยวถัดไปเอง** ตอนวิ่ง (ไม่ต้องจัดกลุ่มล่วงหน้า)
- เหตุผล **เลือกจากรายการ + พิมพ์เอง** (ที่นั่งไม่พอ · รับหลายโรงเรียน · เส้นทางไกล / หลายจุดรับ · อื่น ๆ)
- **โรงเรียน สังกัด จังหวัด** เห็นเที่ยวและเหตุผล (ผู้ปกครองไม่เห็น)

## ทำงานอย่างไร
- ตาราง `vehicle_trips` (migration 062) เก็บเฉพาะเที่ยวที่ 2 ขึ้นไป — เที่ยวที่ 1 ไม่มีแถว · แต่ละเที่ยวจำ `after_log_id` (เลข `checkin_logs.id` ล่าสุดตอนเริ่มเที่ยว) — การเช็กชื่อที่เลขมากกว่าเป็นของเที่ยวนั้น จึงไม่แก้ `checkin_logs` และไม่คลาดเพราะเวลาวินาทีเดียวกัน
- "บนรถ" = นักเรียนที่รายการล่าสุดของรอบนี้ใน `checkin_logs` ของรถคันนี้เป็น `CHECKED_IN`
- เริ่มเที่ยวถัดไปได้เมื่อ **รถว่าง** (บนรถ 0) และ **เที่ยวปัจจุบันมีเด็กขึ้นแล้ว** — กันการกดซ้อน · ไม่เกิน 9 เที่ยว · ล็อกแถวรถกันกดซ้ำ · audit `vehicle_trip`
- คนขับ: การ์ด "เที่ยวที่ N" บนหน้าแรก (`components/TripPanel.jsx`) — มีเด็กบนรถ → "ส่งเด็กกลุ่มนี้ลงครบแล้ว (จบเที่ยวที่ N)" (เรียก checkout-all) · รถว่าง → "เริ่มเที่ยวที่ N+1" + เหตุผล
- โรงเรียน / สังกัด / จังหวัด: เมนู เพิ่มเติม › **รถที่วิ่งหลายเที่ยว** (`pages/shared/VehicleTripsReport.jsx`) ช่วงวันที่ ≤ 31 วัน

## API
- `GET /api/driver/trips?session=` · `POST /api/driver/trips { session, reason_code, reason_text? }`
- `GET /api/{school|affiliation|province}/vehicle-trips?date_from&date_to` — ขอบเขต: โรงเรียน = รถของนักเรียนในโรงเรียน · สังกัด = รถของนักเรียนในโรงเรียนในสังกัด · จังหวัด = ทุกคัน (ไม่มีเบอร์โทร §5.5)
- โค้ด: `backend/src/services/vehicleTrip.service.js`

## เปิดใช้บน production
1. deploy (flag ปิด — ไม่มีอะไรเปลี่ยน)
2. เจ้าของ apply migration 062 (สคริปต์บรรทัดเดียว เหมือน 061)
3. `bash scripts/enable-feature-flag.sh FEATURE_MULTI_TRIP true` แล้วอัปเดต `scripts/production-feature-flags.json`
4. อัปเดตคู่มือคนขับ โรงเรียน สังกัด จังหวัด

## ยังไม่ทำในรอบนี้
หน้าภาพรวม (โรงเรียน/สังกัด/จังหวัด) ยังอาจขึ้น "ค้างเลยเวลา" ระหว่างรอเที่ยวถัดไป — ถ้าต้องการให้รู้ว่ารถกำลังกลับไปรับเที่ยวต่อไป ทำเป็นรอบถัดไป
