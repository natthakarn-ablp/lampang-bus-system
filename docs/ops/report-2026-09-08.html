พบจากการรันถ่ายภาพหน้าจอ ซึ่งเป็นสิ่งเดียวในโครงการนี้ที่เปิดหน้าจอจริง เพิ่มตัวดักที่จับทั้งประเภทของบั๊กแล้ว ทดสอบว่าถอด import ออกอีกครั้งก็แดงทันที

การเปลี่ยนแปลงของวันนี้ ไม่มี migration ไม่มีการเปลี่ยนสวิตช์ และไม่แตะฐานข้อมูล จึงเป็นการปล่อยรุ่นแบบธรรมดา ลำดับเหมือนทุกครั้ง คือสำรองฐานข้อมูลและตรวจสอบไฟล์สำรองก่อน แล้วรันสคริปต์ปล่อยรุ่น ตามด้วย build หน้าเว็บใหม่ แล้วเฝ้าดู 15 นาที

คำสั่ง ssh ของผู้ช่วยถูกตัวกรองบล็อก แม้เป็นการอ่านอย่างเดียว การปล่อยรุ่นจึงต้องให้ผู้ดูแลระบบรันเอง

สิ่งที่ผู้ใช้จะเห็นต่างจากเดิมทันที ข้อความความยาวรหัสผ่านถูกต้องทุกหน้า · ไทม์ไลน์ของเรื่องร้องเรียนมีวันที่ · หน้าสรุปภาพรวมการมีส่วนร่วมที่ยังไม่เคยมีใครเห็น · และหน้ารายงานวิจัยเลิกประกาศแนวโน้มที่ยังเทียบกันไม่ได้

สิ่งที่ทำแทนไม่ได้ ต้องให้คนตัดสิน

ไม่มีข้อไหนติดเรื่องโค้ด ทุกข้อรอคำตอบหรือลายเซ็น

  1. ตอบคำถามสามข้อต่อบทบาท เพื่อเปิดการกู้รหัสผ่านให้จังหวัด สังกัด และขนส่ง กลไกพร้อมแล้ว หน้าจอพร้อมแล้ว รอเพียงคำตอบว่าบัญชีเป็นของบุคคลหรือหน่วยงาน ใครมีอำนาจผูก LINE และจะส่งมอบกันอย่างไรเมื่อเปลี่ยนตัวคน
  2. ส่งใบแจ้งหกสังกัดว่าเขารีเซ็ตรหัสผ่านโรงเรียนเองได้ เอกสารเขียนเสร็จและขึ้นระบบไปตั้งแต่ 7 ก.ย. แต่ยังไม่มีใครส่งให้เขา นี่คือการกระทำเดียวที่ลดภาระผู้ดูแลระบบได้ทันทีโดยไม่ต้องแก้อะไรเลย
  3. ความเห็นของผู้รับผิดชอบข้อมูลส่วนบุคคล ต่อการกู้รหัสผ่านด้วยลิงก์ LINE ด่านเดียว ร่างประเมินผลกระทบเตรียมไว้แล้ว เว้นช่องความเห็นไว้ให้
  4. ตัดสินว่าใครมีอำนาจบันทึกมติในเรื่องร้องเรียนแต่ละประเภท ตอนนี้ผู้ที่เห็นเรื่องบันทึกมติในเรื่องของตัวเองได้ มีเทสต์บันทึกพฤติกรรมนี้ไว้พร้อมคำอธิบายว่าเป็นข้อบกพร่องที่รอการตัดสิน ไม่ใช่การออกแบบ
  5. รับรองย้อนหลังการเปลี่ยนแปลงระบบจริง 17 รายการ บันทึกครบแล้วทุกรายการ รวมถึง 13 รอบที่ไม่เคยมีบันทึกของตัวเอง เหลือเพียงการเลือกว่าจะรับรองบนหลักฐานเท่านี้ หรือให้ดึงไฟล์ผลรันรายรอบจากเซิร์ฟเวอร์มาเติมก่อน
  6. ปิด Browser Insights ในแดชบอร์ดของ Cloudflare ห้ามแก้ด้วยการขยายนโยบายความปลอดภัยของเว็บ
