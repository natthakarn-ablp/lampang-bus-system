# Decision Register — การตัดสินใจที่ค้างอยู่ก่อนเดินงานต่อ

ระบบ: อุ่นใจไปโรงเรียน (School Safe Connect)

จัดทำ: 4 กันยายน 2569 · RC `cef4bd1` · เอกสารอ้างอิง `execution-plan-to-completion-2026-09-04.md` §4.1–§4.2

สถานะเอกสาร: **แบบฟอร์มสำหรับให้ผู้มีอำนาจตัดสินใจกรอก — ยังไม่ใช่การอนุมัติ ไม่ใช่ผลการทดสอบ และไม่ใช่หลักฐานว่าเรื่องใดผ่านแล้ว**

---

## 1. เอกสารนี้คืออะไร

มีการตัดสินใจ **21 ข้อ** ที่ค้างอยู่ และงานเทคนิคอีก 7 Phase หยุดรอคำตอบเหล่านี้อยู่ เอกสารนี้รวบคำถามทั้งหมดไว้ที่เดียว พร้อมทางเลือกและผลกระทบต่อข้อ เพื่อให้ตัดสินได้โดยไม่ต้องไล่อ่านเอกสารทั้งชุด

- **C0-1 … C0-13** — Owner / Product / Research lead / Operator
- **D0-1 … D0-8** — DPO / legal

## 2. กติกาการใช้

1. ผู้ตัดสินกรอก **ในเอกสารนี้เท่านั้น** — ทีมพัฒนาและ AI ห้ามกรอกแทนทุกกรณี
2. ทุกข้อต้องมี **คำตอบ + ชื่อผู้ตัดสิน + วันที่** ครบสามอย่างจึงนับว่าตอบแล้ว
3. ถ้ายังตัดสินไม่ได้ ให้กรอก **วันที่จะตัดสิน** แทน แล้วผูกกับกติกาเลื่อนใน §10 ของ execution plan
4. เมื่อตอบแล้ว ทีมเทคนิคจะอ้าง commit ที่ implement กลับมาที่ข้อนี้ในช่อง "อ้างอิงการ implement"
5. ห้ามถือว่า "validator ผ่าน" หรือ "automated readiness ไม่ FAIL" เป็นคำตอบของข้อใด — เครื่องมือตรวจได้แค่ว่าช่องยังว่าง ไม่ได้ตรวจว่าใครอนุมัติ
6. ชื่อบุคคลและช่องทางติดต่อ ถ้าเป็นข้อมูลส่วนบุคคล ให้กรอกในสำเนาที่เก็บนอก repository
