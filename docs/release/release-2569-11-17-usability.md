# รุ่น 2.1.0 — การใช้งานบัญชีและภาพรวม (17 พฤศจิกายน 2569)

## พฤติกรรมที่เปลี่ยน
- โรงเรียน/สังกัดรีเซ็ตคนขับ: รหัสชั่วคราวอยู่ในหน้าต่างจนกดปิดเอง มีปุ่มคัดลอก โหลดข้อมูลใหม่หลังปิดเท่านั้น รหัสไม่เก็บใน storage หรือ log
- เวลาเช็กชื่อ: แจ้งรายการที่ติดลำดับพร้อมขอบเขตเวลา แก้เวลา/ห้องแล้วลองใหม่ได้ ยังคง transaction ทั้งชุด สิทธิ์ วัน รอบ เวลาอนาคตและประวัติเดิม
- ลืมรหัส: คำขอยังไม่เปลี่ยนรหัสเดิม คำตอบยังเป็นกลางไม่เปิดเผยว่าบัญชีมีอยู่หรือผูก LINE หรือไม่ มีช่องทางติดต่อแยกสิทธิ์
- เปลี่ยนรหัสบังคับ: ออกจากระบบ/เปลี่ยนบัญชีได้ ไม่ข้ามข้อบังคับไปหน้าหลัก; เปลี่ยนโดยสมัครใจยกเลิกกลับหน้าหลักตาม role
- ภาพรวม: รายการหลักสูงสุดสามรายการ พร้อมเปิดดูทั้งหมด; รายละเอียดอนุมัติพับไว้และไม่แสดงคิวศูนย์; ประวัติ/รอผู้อื่นแยกจากงาน admin; ครูเห็นชื่อสายชั้น รายชื่อรอไม่นับกลุ่มไม่มีรถ รายรถไม่นับกลุ่มไม่มีรถเป็นรถ และกราฟวันนี้ใช้ฐานเดียวกับสรุปรอบ
- ประกาศตามสิทธิ์คงเปิดอ่านเอง มีรุ่นและรหัสซอร์สที่ใช้ build

## รุ่นเผยแพร่
`frontend/src/release.json` เป็นเลขรุ่นผู้ใช้และวันที่เผยแพร่ อัปเดตทุก release จริง: patch สำหรับแก้บั๊ก, minor สำหรับเพิ่มความสามารถ, major เมื่อไม่เข้ากันกับรุ่นเดิม หมายเลข package dependency ไม่ใช่หลักฐานรุ่นที่กำลังให้บริการ
Vite อ่าน short SHA จาก Git ของ checkout ตอน build โดยไม่ใช้ token/env secrets; build ต้องมี Git checkout รุ่นจริง CI/production จึงอาจมี source SHA ต่างจาก head PR เมื่อเป็น merge commit ตรวจ backend ด้วย /api/health และตรวจหน้าเว็บด้วยรหัส build ที่แสดง ทั้งสองต้องตรงกับ source ที่ operator เผยแพร่ ไม่ refresh หน้า/ล้างฟอร์มผู้ใช้โดยอัตโนมัติ

## การตรวจและเผยแพร่
ยังไม่เผยแพร่จนกว่าจะผ่าน local regression, quality gates, head CI และ exact-merge CI ใช้ scripts/deploy-backend.sh บน feat/tracking-security-hardening แบบ fast-forward ภายใต้ production reservation/lock สำรองและ verify DB ก่อนดำเนินการ เก็บ rollback backend ref และ dist.prev ของ frontendตามสคริปต์ ไม่มี migration ใหม่ในรุ่นนี้ ไม่ reset บัญชีจริง ไม่ส่ง LINE ไม่เขียนข้อมูลนักเรียนเพื่อทดสอบ

## ข้อจำกัด
รหัสชั่วคราวที่เคยหายไปเรียกคืนไม่ได้ เจ้าหน้าที่ต้องรีเซ็ตใหม่และส่งให้เจ้าของบัญชีหลังเผยแพร่ รุ่นนี้ไม่รีเซ็ตแทนและไม่เผยรหัสในเอกสาร/แชต
ปัญหาหน้า error ที่เคยหายหลัง refresh ยังไม่มีหลักฐาน root cause แยก จึงไม่อ้างว่าแก้แล้วด้วยรุ่นนี้
