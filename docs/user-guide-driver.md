# คู่มือใช้งานสำหรับคนขับรถ

> ระบบรถรับส่งนักเรียนจังหวัดลำปาง — เว็บไซต์ https://schoolbuslampang.com
> เวอร์ชัน Phase 10.11A • อัปเดต 2026-06-02

เอกสารนี้สำหรับคนขับรถที่ใช้บัญชี **driver**
ระบบออกแบบให้ใช้บนมือถือเป็นหลัก แต่ใช้บน tablet/desktop ก็ได้

---

## 1. เข้าสู่ระบบ

1. เปิดเบราว์เซอร์บนมือถือไปที่ **https://schoolbuslampang.com**
2. กรอก **ชื่อผู้ใช้** = **ทะเบียนรถของคุณ** (เช่น `นข 1571 ลำปาง`)
   - เว้นวรรคให้ตรง 1 ที่ระหว่างหมวด-ตัวเลข-จังหวัด
   - ภาษาไทย (ไม่ต้องเปลี่ยนคีย์บอร์ดอังกฤษ)
3. กรอก **รหัสผ่าน** ที่ได้รับ
4. กด **เข้าสู่ระบบ**

### เคล็ดลับ
- บันทึก URL ไว้ใน home screen ของมือถือ (Add to Home Screen)
  → ใช้งานเหมือนแอป
- ใช้ "บันทึกรหัสผ่าน" ของเบราว์เซอร์ได้
- ถ้ามือถือถูกปิดเครื่องระหว่างวัน เปิดมาแล้วยังอยู่ในเซสชันเดิม
  ไม่ต้อง login ใหม่ (token อายุ 24 ชั่วโมง)

## 2. ตรวจสถานะก่อนเริ่มรับ-ส่ง

หน้าแรกหลัง login = **Driver Dashboard** (`/driver`)

### Pretrip Status Pill
- แสดงสรุปก่อนออกรถ:
  - **รอบนี้** (เช้า / เย็น) — ระบบสลับอัตโนมัติตามเวลา (default
    หลังเที่ยงเป็นเย็น)
  - **จำนวนนักเรียนทั้งหมดในรถ**
  - **เหลือ ... คนต้องเช็คอิน** (remaining check-in counter)

ถ้า counter เป็น 0 = เช็คอินครบแล้ว
ถ้า counter > 0 = ยังมีนักเรียนรอเช็คอิน

### ก่อนออกรถควรตรวจ
- [ ] สถานะประกันรถ — ที่ dashboard มี alert ถ้าใกล้หมดอายุ
- [ ] สภาพรถภายนอก (ลม, ไฟ, เบรค)
- [ ] นักเรียนทุกคนใน roster
- [ ] สัญญาณมือถือ + battery > 30%

## 3. ดูรายชื่อนักเรียน (Roster)

1. จากหน้า dashboard กดเมนู **รายชื่อนักเรียน** หรือเลื่อนลงไปดู
2. รายชื่อจะแสดงเรียงตามลำดับการรับ (หรือชื่อ ตามที่ตั้ง)
3. แต่ละแถวแสดง:
   - คำนำหน้า + ชื่อ + นามสกุล
   - ชั้น / ห้อง
   - **สถานะรอบเช้า** — รับแล้ว / ยังไม่รับ / ไม่มา
   - **สถานะรอบเย็น** — ส่งแล้ว / ยังไม่ส่ง
   - **ปุ่ม "เช็คอิน"** (รอบเช้า) หรือ **"เช็คเอาท์"** (รอบเย็น)
   - หากโรงเรียนยืนยันแทนแล้ว — chip **"ครูยืนยันแทนแล้ว"** (ดูข้อ §5)

### Filter
- ดูเฉพาะ "ยังไม่เช็คอิน"
- ดูเฉพาะ "เช็คอินแล้ว"
- ดูเฉพาะ "ไม่มา"

---

## 4. บันทึกรับ-ส่งนักเรียน

### บันทึกทีละคน
1. หานักเรียนใน roster
2. กด **เช็คอิน** (รอบเช้า) หรือ **เช็คเอาท์** (รอบเย็น)
3. ระบบจะ:
   - บันทึก `checkin_logs` พร้อม timestamp + คนที่กด
   - อัพเดต `daily_status` สำหรับวันนี้
   - ส่ง **push notification ทาง LINE** ให้ผู้ปกครอง
   - เปลี่ยนสถานะใน roster ทันที (สีเปลี่ยน, ปุ่มหาย)

### บันทึกพร้อมกันทั้งคัน
- กด **เช็คอินทั้งคัน** ที่ด้านบนของ roster
- ระบบจะ batch เช็คอินทุกคนที่ "ยังไม่เช็คอิน" ในรอบนั้น
- ใช้เมื่อรับนักเรียนพร้อมกันที่จุดเดียวกัน (ลานโรงเรียน)
- ผู้ปกครองทุกคนจะได้รับ push พร้อมกัน

### บันทึก "ไม่มา"
- ถ้านักเรียนไม่มาขึ้นรถ กดที่ชื่อ → เลือก **"ไม่มา (ABSENT)"**
- ผู้ปกครองได้รับแจ้งเตือน

### ถ้ากดผิด
- การเปลี่ยนสถานะใหม่จะสร้าง row ใหม่ใน `checkin_logs`
  (ระบบเก็บประวัติทั้งหมด)
- ไม่ลบ record เดิม — เพื่อ audit trail
- ติดต่อโรงเรียนถ้าต้องการให้แก้สถานะอย่างเป็นทางการ

## 5. ป้าย "ครูยืนยันแทนแล้ว" คืออะไร

ในรายชื่อนักเรียน บางแถวอาจมี chip สีฟ้า/เทาเล็ก ๆ ว่า
**"ครูยืนยันแทนแล้ว"** ปรากฏที่ด้านขวาของชื่อ

### ความหมาย
- โรงเรียนได้ใช้ฟีเจอร์ "ยืนยันแทนคนขับ" (school override) บันทึก
  สถานะของนักเรียนคนนั้นไปแล้วในวันนี้
- เกิดในกรณี เช่น:
  - คนขับลืมกดเช็คอิน → ครูเห็นนักเรียนถึงโรงเรียนแล้ว → ครูยืนยันแทน
  - สัญญาณคนขับขาด → ครูบันทึกแทน
  - มีข้อพิพาท → ครูเป็นผู้ตัดสินใจ

### ต้องทำอะไรไหม
- **ไม่ต้องทำอะไรเพิ่ม** — chip นี้เป็นข้อมูล (read-only)
- คนขับยังกดเช็คอินซ้ำได้ ถ้าจำเป็น (จะมี record ใหม่ใน `checkin_logs`
  ทับลงไป แต่ของครูที่ยืนยันแทนก็ยังอยู่ใน audit log)
- ผู้ปกครองได้รับแจ้งเตือนแล้วจากการ override ของครู
  (จะไม่ได้รับ double-notify จากคนขับเช็คอินซ้ำในบางกรณี ขึ้นกับ design)

### ถ้าคิดว่าครู override ผิดพลาด
- ติดต่อโรงเรียนโดยตรง
- อย่ากดอะไรเพิ่มก่อนปรึกษา
- ระบบมี audit log บันทึกว่าครูคนไหนทำ override + เหตุผล

## 6. แจ้งเหตุฉุกเฉิน

### เมื่อไหร่ใช้
- อุบัติเหตุ
- รถเสีย
- นักเรียนเจ็บป่วยกะทันหัน
- เหตุการณ์ที่ต้องแจ้งโรงเรียน/ผู้ปกครอง/หน่วยงานทันที

### ขั้นตอน
1. จากหน้า dashboard กดปุ่ม **🚨 แจ้งเหตุฉุกเฉิน**
   (สีแดง — เห็นได้ชัด)
2. Modal เปิด — กรอก:
   - **รายละเอียดเหตุการณ์** (สั้น ๆ ก็ได้ ตอนเร่งด่วน)
   - **โน้ตเพิ่มเติม** (option)
3. กด **ยืนยันแจ้งเหตุ**

### ระบบจะ
- บันทึก `emergency_logs` พร้อม timestamp + ทะเบียนรถ + คนที่แจ้ง
- ส่ง push notification ไปยัง LINE group ของผู้ดูแลทันที (ถ้า
  configured)
- ผู้ดูแลโรงเรียน + เขตพื้นที่จะเห็น emergency ในหน้า dashboard

### หลังเหตุการณ์สงบ
- อัพเดต result/note เพิ่มเติมในระบบ
- ถ้าผู้ดูแลปิดเหตุการณ์ จะมี timestamp ปิด

> ⚠️ **อย่าใช้ปุ่มฉุกเฉินเป็นปุ่มเรียกประจำ** — ทุกครั้งที่กดจะ
> แจ้งทุกคนในกลุ่ม

## 7. ใช้งานบนมือถือ

ระบบนี้ออกแบบ mobile-first สำหรับคนขับ:

### ขนาดปุ่ม
- ปุ่มหลัก (เช็คอิน, เช็คเอาท์, ฉุกเฉิน) ขนาด ≥ 44×44 px
- กดด้วยนิ้วโป้งขณะถือมือถือมือเดียวได้

### ไม่ต้อง pinch zoom
- หน้าจอ responsive — ปรับให้พอดีจอเอง
- ถ้าตัวอักษรเล็กไป ใช้ system text size ของมือถือเพิ่มให้ใหญ่ขึ้น

### ใช้ขณะรถจอด
- เพื่อความปลอดภัย ห้ามเช็คอิน/เช็คเอาท์ขณะขับ
- หาที่จอดเสียก่อน แล้วค่อยกด

### Mobile bottom nav
- คนขับมีแท็บล่างให้กดง่าย (ขึ้นกับ design ของ role)

### ออฟไลน์
- ระบบนี้ **ต้องออนไลน์** ตอนเช็คอิน (ส่งไป API)
- ถ้าสัญญาณขาด: รอจนสัญญาณกลับมาแล้วลองใหม่
- ระบบจะแสดง error toast ถ้า save ไม่ได้

## 8. เมื่อพบปัญหา

| อาการ | สิ่งที่ทำ |
|---|---|
| Login ไม่ได้ — รหัสผิด | ตรวจรหัสผ่าน; ถ้าจำไม่ได้ติดต่อ admin โรงเรียน |
| Login ไม่ได้ — ทะเบียนผิด | ตรวจการสะกด: หมวด-ช่องว่าง-เลข-ช่องว่าง-จังหวัด |
| กดเช็คอินแล้วไม่มีอะไรเกิดขึ้น | ดูสัญญาณ; ถ้า WiFi/4G OK ลองอีกครั้ง |
| สถานะไม่อัพเดต | ดึงหน้าลง (pull-to-refresh) หรือกด F5 |
| ขึ้น "เซสชันหมดอายุ" | login ใหม่ (token อายุ 24 ชม.) |
| ไม่เห็นนักเรียนบางคน | ติดต่อโรงเรียน — อาจถูกลบหรือเปลี่ยนรถ |
| ผู้ปกครองบ่นไม่ได้รับ LINE | ขอให้ผู้ปกครองตรวจการผูกบัญชี (พิมพ์ `สถานะ` ใน LINE) |
| ปุ่มฉุกเฉินไม่ทำงาน | สัญญาณอาจขาด — โทรหา emergency contact โดยตรง |

หากปัญหายังอยู่ ส่งให้ทีม:
- ทะเบียนรถ
- เวลาที่เกิดปัญหา
- screenshot
- network ตอนนั้น (4G/WiFi)
