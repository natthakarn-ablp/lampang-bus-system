# คู่มือใช้งานสำหรับโรงเรียน

> ระบบรถรับส่งนักเรียนจังหวัดลำปาง — เว็บไซต์ https://schoolbuslampang.com
> เวอร์ชัน Phase 10.11A • อัปเดต 2026-06-02

เอกสารนี้สำหรับเจ้าหน้าที่/ครูที่ใช้บัญชี **โรงเรียน (school)**
ครอบคลุมทั้งบัญชีหลักของโรงเรียน (full account) และบัญชีครูสายชั้น
(grade-scoped teacher)

---

## 1. เข้าสู่ระบบ

1. เปิดเบราว์เซอร์ (Chrome / Safari) ไปที่ **https://schoolbuslampang.com**
2. หน้า login จะปรากฏขึ้น
3. กรอก **ชื่อผู้ใช้ (username)** ที่โรงเรียนได้รับ
4. กรอก **รหัสผ่าน**
5. กด **เข้าสู่ระบบ**

### ถ้าเข้าระบบไม่ได้
- ตรวจชื่อผู้ใช้และรหัสผ่านอีกครั้ง (อักษรพิมพ์ใหญ่-เล็กสำคัญ)
- ถ้าขึ้น "มีการพยายามเข้าสู่ระบบหลายครั้ง" รอ ~15 นาทีแล้วลองใหม่
  (ระบบไม่ล็อกถาวร)
- ถ้าจำรหัสผ่านไม่ได้ ติดต่อผู้ดูแลระบบเพื่อรีเซ็ต
- ครั้งแรกที่ login (หรือเมื่อถูกรีเซ็ตรหัสผ่าน) ระบบจะบังคับให้
  เปลี่ยนรหัสผ่านก่อนใช้งาน

### บัญชีของฉันเห็นอะไรบ้าง?
- **บัญชีหลักโรงเรียน (full account)**: เห็นนักเรียนทุกชั้น
  + จัดการได้
- **บัญชีครูสายชั้น (grade-scoped teacher)**: เห็นเฉพาะนักเรียนในชั้น
  ที่ผูกไว้กับบัญชี + อ่านอย่างเดียวเป็นส่วนใหญ่
  (รายละเอียดในข้อ §8)

## 2. หน้าแดชบอร์ด (Dashboard)

หน้าแรกหลัง login จะเป็น `/school`

### แถบบนสุด (Action Row)
- **เพิ่มนักเรียน** — เปิดฟอร์มเพิ่มนักเรียนใหม่
- **จัดการรถ** — ไปหน้ารถของโรงเรียน
- **รายงานวันนี้** — ดูสรุปการเช็คอินวันนี้

> ครูสายชั้นจะ **ไม่เห็น** ปุ่ม "เพิ่มนักเรียน" และ "จัดการรถ"

### Session Hero Cards
- **รอบเช้า** — สรุปสถานะรับนักเรียนรอบเช้า (ขึ้นรถแล้วกี่คน / รอกี่คน)
- **รอบเย็น** — สรุปสถานะส่งนักเรียนรอบเย็น
- มี indicator สี: เขียว = ครบ, ส้ม = บางคนยังไม่เช็คอิน,
  เทา = ยังไม่ถึงเวลา

### Alert Strip
- แสดงเหตุการณ์สำคัญ เช่น รถใกล้หมดประกัน, นักเรียนยังไม่เช็คอิน
  ที่ควรต้องตรวจสอบ

### Analytics (พับไว้ด้านล่าง)
- กราฟแนวโน้มและสถิติย้อนหลัง — กดขยายเมื่ออยากดูรายละเอียด

### Mobile Bottom Nav (เฉพาะหน้าจอ ≤ 768 px)
- 4 แท็บล่าง: **หน้าแรก / ค้นหา / ตำแหน่ง / รายงาน**

## 3. ค้นหานักเรียน

1. กดเมนู **ค้นหา** (หรือไปที่ `/school/students`)
2. พิมพ์ชื่อ, นามสกุล หรือรหัสนักเรียนในช่องค้นหา
3. ผลลัพธ์จะปรากฏเป็นตาราง พร้อมข้อมูล:
   - คำนำหน้า + ชื่อ + นามสกุล
   - ชั้น / ห้อง
   - รถที่ใช้บริการ
   - สถานะการเช็คอินวันนี้

### กรองและจัดเรียง
- กรองตาม **ชั้น**, **รถ**, **ใช้บริการรอบเช้า/เย็น**
- คลิกหัวคอลัมน์เพื่อจัดเรียง

### กดเข้าดูรายละเอียดนักเรียน
- จากตารางผลค้นหา กดที่ชื่อนักเรียน → หน้ารายละเอียด
- สามารถดูประวัติการขึ้นลงรถย้อนหลังได้

### เพิ่ม / แก้ไข / ลบนักเรียน (เฉพาะบัญชีหลักโรงเรียน)
- **เพิ่ม**: กดปุ่ม "เพิ่มนักเรียน" → กรอกฟอร์ม → บันทึก
- **แก้ไข**: เปิดรายละเอียด → กด "แก้ไข"
- **ลบ**: เปิดรายละเอียด → กด "ลบ" (เป็น soft delete; กู้คืนได้)

### นำเข้านักเรียนจาก Excel/CSV
1. ไปที่ `/school/students/import`
2. ดาวน์โหลด template
3. กรอกข้อมูลให้ครบ
4. อัพโหลดไฟล์ → ระบบสร้าง **import_batch**
5. ดูผลการนำเข้า (success/error per row) ที่ `/school/import-batches`

---

## 4. จัดการรถ (เฉพาะบัญชีหลักโรงเรียน)

1. กดเมนู **จัดการรถ** (หรือไปที่ `/school/vehicles`)
2. ดูรายการรถที่ให้บริการโรงเรียน
3. แต่ละแถวแสดง:
   - ทะเบียนรถ
   - ประเภท
   - คนขับปัจจุบัน
   - สถานะประกัน + วันหมดอายุ
   - สถานะการตรวจสภาพล่าสุด

### เพิ่ม / แก้ไขรถ
- กด "เพิ่มรถ" → กรอกทะเบียน, ประเภท, ข้อมูลประกัน, ผู้ครอบครอง
- กดที่แถวรถ → "แก้ไข" → อัพเดตข้อมูล

### ผูกคนขับกับรถ
- เปิดรายละเอียดรถ → ส่วน "การมอบหมาย" (driver_vehicle_assignments)
- เลือกคนขับ + วันที่เริ่ม → บันทึก
- หากต้องการสลับคนขับ: end_date ของ assignment เก่า + สร้าง assignment ใหม่

---

## 5. รายงานวันนี้

1. กดเมนู **รายงานวันนี้** (หรือ `/school/reports/daily`)
2. หน้าแสดง:
   - จำนวนนักเรียนทั้งหมดที่ใช้บริการวันนี้
   - จำนวนที่เช็คอินแล้ว (รอบเช้า / รอบเย็น)
   - รายชื่อนักเรียนที่ยังไม่เช็คอิน
   - เหตุการณ์ฉุกเฉินที่บันทึกไว้
3. กรองตามวัน / รถได้
4. กด **ส่งออก** → เลือก Excel / CSV / PDF

### รายงานรายเดือน
- ที่ `/school/reports/monthly` — สรุปยอดเช็คอินรายวันในเดือนนั้น
- สามารถส่งออกได้เช่นกัน

## 6. ยืนยันแทนคนขับ (School Override)

> **เฉพาะบัญชีหลักโรงเรียน** — ครูสายชั้นจะไม่เห็นปุ่มนี้

ใช้เมื่อคนขับลืมเช็คอิน/เช็คเอาท์นักเรียน หรือเกิดเหตุที่ต้องบันทึก
สถานะแทน

### ขั้นตอน
1. ไปที่หน้า dashboard หรือ student detail
2. กดปุ่ม **ยืนยันแทนคนขับ**
3. Modal เปิดขึ้น — เลือก:
   - **นักเรียน** (เฉพาะที่อยู่ในขอบเขตโรงเรียนของคุณ)
   - **รอบ** (รอบเช้า / รอบเย็น)
   - **สถานะ** (รับแล้ว / ส่งแล้ว / ไม่มา / ยกเลิก)
4. กรอก **เหตุผล** (จำเป็น — บันทึกใน audit log)
5. กดยืนยัน

### หลังยืนยัน
- DB จะมี record ใน `checkin_logs` พร้อม flag `override_by_school=true`
- มี audit log ที่บันทึก user ที่ทำ override + เหตุผล
- **ผู้ปกครองของนักเรียนคนนั้นได้รับแจ้งเตือนทาง LINE** (รวมถึงพี่น้องที่ใช้
  เบอร์โทรเดียวกันด้วย)
- บนหน้า driver ของรถนั้น จะมี chip **"ครูยืนยันแทนแล้ว"** ปรากฏที่
  แถวนักเรียน (read-only — คนขับยังกดเช็คอินซ้ำได้ถ้าจำเป็น)

---

## 7. ข้อควรระวังในการใช้งาน "ยืนยันแทนคนขับ"

ฟีเจอร์นี้มีผลทั้งต่อ DB และผู้ปกครอง ใช้อย่างระมัดระวัง:

| ข้อ | คำอธิบาย |
|---|---|
| ใช้เฉพาะเมื่อจำเป็น | เช่น คนขับลืมเช็คอิน, สัญญาณมือถือไม่ดี ไม่ใช่ใช้แทนรายวัน |
| กรอกเหตุผลที่ตรวจสอบได้ | "นักเรียนมารถจริง ครูเห็นด้วยตัวเอง 07:45" ดีกว่า "OK" |
| ผู้ปกครองได้ push เสมอ | อย่ายืนยันแทนเล่น เพราะระบบจะส่งแจ้งเตือนทันที |
| audit log เห็นชื่อคุณ | ระบบบันทึกว่าใครยืนยัน เวลาไหน เหตุผลอะไร |
| กลับคำไม่ได้ตรง ๆ | ถ้าผิด ต้องลงสถานะใหม่ (เช่น CANCELLED) แทนการลบ — เพื่อ trail |
| ครูสายชั้นทำไม่ได้ | ถ้าจำเป็น ให้บัญชีหลักโรงเรียนเป็นผู้ทำ |
| ห้ามใช้แทนผู้ปกครอง | ถ้าผู้ปกครองอยากแจ้ง "ลาวันนี้" ต้องผ่าน LINE หรือโทรหาคนขับ ไม่ใช่โรงเรียน override |

## 8. บัญชีครูสายชั้น (grade-scoped teacher) — เห็น/ไม่เห็นอะไร

ครูสายชั้นมีสิทธิ์จำกัดเพื่อให้ดูแลเฉพาะชั้นของตน:

### เห็น (อ่านได้)
- ✅ นักเรียนในชั้นที่ผูกไว้กับบัญชี (เช่น ครู ป.3 เห็นเฉพาะ ป.3)
- ✅ สถานะการเช็คอินของนักเรียนในชั้นนั้น
- ✅ รายงานรายวัน / รายเดือน ที่ scope ของชั้นเห็นได้
- ✅ Scope chip ที่ header dashboard บอกว่า "ครู ป.3" หรือชั้นอะไร

### ไม่เห็น (ระบบซ่อน)
- ❌ ปุ่ม "เพิ่มนักเรียน"
- ❌ ปุ่ม "จัดการรถ"
- ❌ ปุ่ม "ยืนยันแทนคนขับ"
- ❌ นักเรียนนอกชั้นของตน (ทั้งใน list และค้นหา)
- ❌ ข้อมูลโรงเรียนอื่น (403)

### ถ้าครูสายชั้นเผลอ Hit URL ของฟีเจอร์ที่ไม่มีสิทธิ์
- Frontend redirect กลับ dashboard
- Backend ตอบ 403 (เช่น `POST /api/school/checkin-override` → blocked
  โดย `requireFullSchoolScope` middleware)

## 9. ส่งตรวจและรับรองรถ (เพิ่ม 2026-06-22)

> ฟีเจอร์ใหม่ — ใช้ได้หลัง migration 038/039 ถูกรันบน production
> ดูรายละเอียดใน [`docs/UPDATE-2026-06-22.md`](UPDATE-2026-06-22.md)

### 9.1 ภาพรวม

เมนู **ส่งตรวจและรับรองรถ** (`/school/vehicle-verification`) ให้โรงเรียน
สร้าง "ใบส่งตรวจรวม" สำหรับรถที่นักเรียนของโรงเรียนใช้บริการ แล้วส่งต่อให้
เจ้าหน้าที่ขนส่งจังหวัดลำปางตรวจรับรองในระบบ โดยไม่ต้องทำเอกสารกระดาษซ้ำ
สำหรับรถที่ใช้ร่วมกันหลายโรงเรียน

### 9.2 สิ่งที่โรงเรียนทำได้

1. เข้าเมนู **ส่งตรวจและรับรองรถ** จาก sidebar
2. เห็นรายการรถของโรงเรียน + สถานะคำขอตรวจปัจจุบัน
3. กด **สร้างคำขอ** สำหรับรถคันที่ต้องการส่งตรวจ
4. ระบบรวมข้อมูลทุกโรงเรียนที่ใช้รถคันเดียวกันโดยอัตโนมัติ:
   - จำนวนผู้โดยสารรอบเช้า / รอบเย็น / จำนวนสูงสุดต่อรอบ
   - พื้นที่รับส่งโดยสรุป (ไม่มีรายชื่อนักเรียน)
5. ระบบสร้างเลขคำขอ + QR code สำหรับเปิดเอกสาร
6. กด **ยืนยันเอกสารพร้อมพิมพ์** เพื่อพิมพ์ใบส่งตรวจพร้อม QR ให้เจ้าของรถ
   นำไปยื่นตรวจตามขั้นตอนของขนส่งจังหวัดลำปาง
7. ติดตามสถานะคำขอ (รอรับรถ / กำลังตรวจ / ผ่าน / ไม่ผ่าน / ต้องแก้ไข)

### 9.3 ข้อจำกัด

- รถหนึ่งคันมีคำขอที่กำลังดำเนินการได้เพียงชุดเดียวต่อภาคเรียน
- โรงเรียนที่ใช้รถร่วมกันสามารถดูสถานะคำขอเดียวกันได้ ไม่ต้องทำซ้ำ
- บัญชีครูสายชั้นดูสถานะได้ แต่สร้างหรือยกเลิกคำขอไม่ได้
- ข้อมูลที่ส่งให้ขนส่ง **ไม่มี** รายชื่อนักเรียน ชื่อผู้ปกครอง เบอร์โทร หรือ
  รหัสประจำตัว (PDPA)

### 9.4 การยกเลิกคำขอ

- กด **ยกเลิกคำขอ** ที่คำขอที่ยังไม่เริ่มตรวจ
- ระบบบันทึก audit log ทุกการเปลี่ยนสถานะ

## 10. ข้อแนะนำการใช้บนมือถือ

หน้าโรงเรียนถูกออกแบบให้ใช้บนมือถือ (375 px ขึ้นไป) ได้สะดวก:

- ใช้ **Mobile Bottom Nav** ด้านล่างเพื่อสลับหน้าหลักได้เร็ว
- ปุ่มหลักมีขนาดอย่างน้อย 44×44 px เพื่อให้นิ้วโป้งกดถนัด
- ในจอแคบ analytics card จะพับลงด้านล่างให้ action card อยู่ด้านบน
- ไม่ควรขยาย/ย่อด้วย pinch zoom — layout responsive แล้ว

## 11. เมื่อพบปัญหา

| อาการ | สาเหตุที่เป็นไปได้ | สิ่งที่ทำ |
|---|---|---|
| เปิดหน้าแล้วโหลดค้าง | network ช้า / backend อืม | รอ 5 วินาที; ถ้าค้างนาน F5 refresh |
| ขึ้น "ไม่มีสิทธิ์เข้าถึง" | บัญชี role/scope ไม่ตรง | login ด้วยบัญชีที่ถูกต้อง; ถ้ามั่นใจว่าควรเข้าได้ ติดต่อ admin |
| ค้นหานักเรียนแล้วไม่เจอ | นักเรียนถูก soft-delete หรืออยู่คนละโรงเรียน | ตรวจ filter, ถามบัญชีหลักโรงเรียน |
| save form แล้วเด้ง error | validation error | อ่านข้อความ error; แก้ field ที่ระบุแล้วลองใหม่ |
| ขึ้น "เซสชันหมดอายุ" | JWT หมด (24 ชม.) | login ใหม่ |
| รายงานส่งออกไม่ทำงาน | popup blocker / sandbox | อนุญาต popup สำหรับ schoolbuslampang.com |

หากปัญหายังอยู่ ติดต่อทีมเทคนิคพร้อมข้อมูล:
- URL ที่เปิด
- เวลา (ประมาณ)
- screenshot ของ error
