## 1. เข้าสู่ระบบ (ทุกบทบาท)

1. เปิดเบราว์เซอร์ไปที่ **https://schoolbuslampang.com**
2. กรอก **ชื่อผู้ใช้** + **รหัสผ่าน** ที่ได้รับ
3. กด **เข้าสู่ระบบ** — ระบบจะ redirect ไป dashboard ของบทบาทเอง:
   - Transport → `/transport`
   - Province → `/province`
   - Affiliation → `/affiliation`

ครั้งแรกที่ login (หรือเมื่อถูกรีเซ็ตรหัสผ่าน) ระบบจะบังคับให้

## 2. ภาพรวมแต่ละบทบาท

### 2.1 ขนส่ง (Transport)

ขนส่งดูแลสภาพรถและการตรวจสภาพ — **ไม่มีสิทธิ์ดูข้อมูลนักเรียน**

| เห็น | ไม่เห็น |
|---|---|
| ✅ รถทั้งหมดในโครงการ + ข้อมูลประกัน | ❌ จำนวนนักเรียน |
| ✅ สถานะการตรวจสภาพรถ | ❌ ชื่อนักเรียน |
| ✅ จุดรับ-ส่งของแต่ละรถ (จุด ไม่ใช่คน) | ❌ ข้อมูลผู้ปกครอง |
| ✅ ประวัติ inspection | ❌ checkin logs ของนักเรียน |
| ✅ Audit log ของตัวเอง | ❌ audit log ของ role อื่น |

> 🔒 **PDPA**: ฟีเจอร์ Phase 10.8UX ถอดตัวเลข/รายชื่อนักเรียนออกจาก
> dashboard ขนส่งทั้งหมด

### 2.2 จังหวัด (Province)

จังหวัดมีสิทธิ์อ่านทั้งจังหวัด — สำหรับผู้กำหนดนโยบายและ stakeholder
ระดับสภาองค์กรของผู้บริโภค

| เห็น | สิทธิ์ |
|---|---|
| ทุกโรงเรียน / ทุกเขต / ทุกรถ | อ่านอย่างเดียว |
| Dashboard 5 cards (วันนี้ / รถ / โรงเรียน / แจ้งเตือน / รายงาน) | ดู + กดเข้า drill-down |
| Live vehicle map | ดูตำแหน่งรถจริง |
| Emergency overview | ดู `emergency_logs` (filter `is_deleted=FALSE`) |
| Reports รายวัน / รายเดือน / รายปี | export ได้ทุก format |
| Audit logs | ดูได้ (มี filter วัน/role/action) |
| System params | ปรับค่าระบบ (บางตัว) ได้ |

### 2.3 สังกัด / เขตพื้นที่ (Affiliation)

สังกัด = สำนักงานเขตพื้นที่การศึกษา (สพป.) ดูภาพรวมโรงเรียนในเขต

| เห็น | สิทธิ์ |
|---|---|
| 5-card school checklist dashboard | adoption rate, data quality, signal |
| โรงเรียนในเขต (เท่านั้น — โรงเรียนเขตอื่น 403) | ดู + drill-down |
| สถานะการเข้าใช้ระบบของแต่ละโรงเรียน | indicator: active / pending / risk |
| Live vehicles ในเขต | map view |
| Risk / action panels | list โรงเรียนที่ต้องดำเนินการ |
| Reports รายเขต / รายโรงเรียน | export ได้ |
| Audit logs ในเขต | ดูได้ |

## 3. Dashboard cards

แต่ละบทบาทเห็น dashboard ที่ออกแบบเฉพาะ:

### Province (5-card executive)
1. **วันนี้** — สรุปเช็คอินทั้งจังหวัด
2. **รถ** — KPI bucket ของรถ (พร้อมใช้ / ใกล้หมดประกัน / เสีย)
3. **โรงเรียน** — จำนวน + status overview
4. **แจ้งเตือน** — เหตุการณ์ที่ต้องดำเนินการ
5. **รายงาน** — quick link ไปยังรายงานหลัก

### Affiliation (5-card school checklist)
1. **โรงเรียน Active** — login + use ระบบล่าสุดภายใน 7 วัน
2. **โรงเรียน Pending** — ยังไม่ active แต่มีข้อมูล
3. **โรงเรียน Risk** — ไม่ active > 14 วัน หรือ data quality ต่ำ
4. **Data Quality** — KPI bucket ของความครบถ้วนข้อมูลนักเรียน/รถ
5. **Action Required** — list โรงเรียนที่ต้องการความช่วยเหลือ

### Transport (PDPA-clean)
- **รถใกล้หมดประกัน** — สีเหลือง = 30 วัน, สีแดง = 7 วัน
- **รถใกล้หมดอายุการตรวจสภาพ**
- **รถ pending inspection**
- **Inspection history** — ผลตรวจย้อนหลัง

> ทุก card ของ Transport ไม่มีตัวเลขนักเรียนเลย — ตามนโยบาย PDPA

## 5. Live Vehicle / Pickup Map

### Province + Affiliation
1. กดเมนู **ตำแหน่ง** (หรือ `/province/live-vehicles` / `/affiliation/live-vehicles`)
2. เห็นรถที่อยู่ในขอบเขตของคุณ pin บนแผนที่ลำปาง
3. คลิกแต่ละ pin → ดู:
   - ทะเบียนรถ
   - คนขับปัจจุบัน
   - โรงเรียนที่ให้บริการ
   - timestamp ล่าสุดที่อัพเดตตำแหน่ง

### Transport (pickup map)
- map แสดง **จุดรับ-ส่งของรถแต่ละคัน** เท่านั้น
- **ไม่ระบุชื่อนักเรียนรายบุคคล** (PDPA)
- ใช้สำหรับวางแผนเส้นทาง / ดูคุณภาพข้อมูลจุดรับ-ส่ง

## 6. Inspection (เฉพาะ Transport)

### บันทึกผลตรวจสภาพรถ
1. ไปที่ `/transport/inspections`
2. กดปุ่ม **เพิ่มผลตรวจ** หรือเลือกจาก list รถ pending
3. กรอก:
   - **รถ** (เลือกจาก list)
   - **วันที่ตรวจ**
   - **ผลตรวจ**: `PASSED` (ผ่าน) / `FAILED` (ไม่ผ่าน) / `NEEDS_FIX` (ต้องแก้)
   - **วันหมดอายุ** (ของใบรับรองที่ออก)
   - **โน้ต** (ถ้ามี)
4. กด **บันทึก**

### ระบบจะ
- เขียน `vehicle_inspections` พร้อม `inspected_by = user.id`
- สถานะรถใน dashboard ของโรงเรียน + จังหวัด + เขตอัพเดตทันที
- audit_log บันทึกการสร้าง/แก้ไข

### Filter
- ดูรถที่ **ยังไม่ตรวจ** (`PENDING`)
- ดูรถที่ **ใกล้หมดอายุ** (≤ 30 วัน)
- ดูรถที่ **หมดอายุแล้ว**
- ดูรถที่ **FAILED** หรือ `NEEDS_FIX` ที่ยังไม่แก้

### แก้ไขผลตรวจ
- กดที่ row inspection → "แก้ไข"
- ระบบเก็บประวัติแก้ไขใน audit_log

## 7. Reports

## 8. ข้อจำกัดด้านข้อมูลส่วนบุคคล (PDPA)

ทุก role ในกลุ่มนี้ต้องเข้าใจ:

### Transport
- ❌ ไม่ดูชื่อนักเรียน
- ❌ ไม่ดูจำนวนนักเรียน
- ❌ ไม่ดูประวัติเช็คอินของนักเรียน
- ✅ ดูเฉพาะ "รถมีจุดรับ-ส่งกี่จุด" — เป็นข้อมูลรถ ไม่ใช่คน

### Province / Affiliation
- ✅ ดูจำนวน (aggregate) ได้
- ⚠️ ดูชื่อนักเรียนต้อง drill-down เป็นเคส ๆ — อย่า export bulk
- ⚠️ ชื่อ-เบอร์ผู้ปกครองเป็นข้อมูลส่วนบุคคล — อย่า export bulk ออกนอกองค์กร

### ทั้ง 3 role
- ❌ ห้ามแชร์ login credential
- ❌ ห้าม screenshot screen ที่มีข้อมูลส่วนบุคคลแล้วโพสต์ใน social
- ✅ ใช้เครื่องส่วนตัว / องค์กร เท่านั้น (ไม่ใช่เครื่องสาธารณะ)
- ✅ Logout ทุกครั้งหลังใช้งานเสร็จ (โดยเฉพาะถ้าใช้เครื่อง shared)

## 9. ฟีเจอร์ใหม่ 2026-06-22 — ตรวจรับรองรถ + ความพร้อมเปิดใช้งาน

> ฟีเจอร์เหล่านี้ใช้ได้หลัง migration 038/039 ถูกรันบน production
> ดูรายละเอียดใน [`docs/UPDATE-2026-06-22.md`](UPDATE-2026-06-22.md)

### 9.1 ขนส่ง — คิวตรวจรับรองรถ (Verification Queue)

เมนู **ตรวจรับรองรถ** (`/transport/verification`) สำหรับเจ้าหน้าที่ขนส่ง
จังหวัดลำปาง ทำงานแทน (หรือเสริม) การตรวจสภาพรถแบบเดิม:

1. เข้าเมนู **ตรวจรับรองรถ** จาก sidebar
2. ค้นหาคำขอด้วย **ทะเบียนรถ**, **เลขคำขอ**, หรือ **โรงเรียน**
3. กรองตามสถานะ: รอรับรถ / กำลังตรวจ / ต้องแก้ไข / ผ่าน / ไม่ผ่าน
4. เปิดรายละเอียดเพื่อตรวจข้อมูลรถ ความจุ จำนวนผู้โดยสารสูงสุด โรงเรียน
   พื้นที่รับส่ง และคนขับหลัก/สำรอง
5. กด **เริ่มการตรวจครั้งใหม่** ทุกครั้งที่รถเข้าตรวจ — ประวัติครั้งก่อน
   จะไม่ถูกแก้ทับ (append-only)
6. ใช้ checklist แบบมีเวอร์ชัน — ระบุผลทุกหัวข้อ; หัวข้อที่ไม่ผ่านต้องเขียน
   รายละเอียด
7. เลือกผลรวม: **ผ่าน / ต้องแก้ไข / ไม่ผ่าน / รอข้อมูลเพิ่ม** และกรอกวัน
   หมดอายุเมื่อผลเป็น "ผ่าน"
8. ระบบอัปเดตสถานะรถอัตโนมัติจากผลตรวจ + เอกสาร + ความจุ + คนขับที่
   คุณสมบัติยังใช้ได้

### 9.2 ขนส่ง — จัดการคนขับหลัก/สำรอง

จากหน้าคิวตรวจ สามารถ:

- เพิ่มคนขับหลัก/สำรองให้รถ (รถหนึ่งคันมีคนขับได้หลายคน)
- รับรองเลขใบอนุญาต + ประเภท + วันหมดอายุ + เลขอ้างอิง
- การเพิ่มคนขับสำรองไม่ยกเลิกคนขับเดิม

### 9.3 จังหวัด — หน้าความพร้อมเปิดใช้งาน (Deployment Readiness)

เมนู **ความพร้อมเปิดใช้งาน** (`/province/readiness`) สำหรับผู้กำหนด
นโยบายระดับจังหวัด:

1. เข้าเมนู **ความพร้อมเปิดใช้งาน** จาก sidebar
2. เห็น bucket สรุประดับจังหวัด:
   - รถทั้งหมด แยกตามสถานะ (UNVERIFIED / ELIGIBLE / EXPIRING /
     INELIGIBLE / SUSPENDED)
   - รถที่มี certified capacity
   - รถที่ผลตรวจล่าสุด PASSED และยังไม่หมดอายุ
   - รถที่เอกสาร (ประกัน/ทะเบียน/พ.ร.บ./ภาษี) ยังใช้ได้
   - บัญชีคนขับที่ผูก `driver_id` vs ยังไม่ผูก
   - คนขับที่มี qualification VERIFIED และใบอนุญาตยังไม่หมดอายุ
   - รถที่มีคนขับ AUTHORIZED อย่างน้อยหนึ่งคน
3. ตาราง "gap" แสดงรายการที่ยังขาด พร้อมผู้รับผิดชอบและการดำเนินการต่อไป
4. หน้านี้ **อ่านอย่างเดียว** ไม่มี PII (เฉพาะตัวเลขรวมและ label)

> หมายเหตุ: ปัจจุบันเป็น aggregate ระดับจังหวัดเท่านั้น ยังไม่มี drill-down
> รายโรงเรียน/รายเขต

### 9.4 ผู้ดูแลระบบ — เมนูเดียวกับจังหวัด

admin เข้า `/admin/readiness` เห็นหน้าเดียวกับ province

## 10. การใช้งานบนมือถือ

ทั้ง 3 role มี **Mobile Bottom Nav** บนหน้าจอ ≤ 768 px (ยกเว้น Transport
ที่ออกแบบเน้น desktop เป็นหลัก)

### Province / Affiliation บน 375 px
- 4 แท็บล่าง: `หน้าแรก / โรงเรียน / ตำแหน่ง / รายงาน`
- Dashboard 5-card วางซ้อนแนวตั้ง
- Map ใช้ pan/zoom ปกติ
- Action row ยังคงอยู่ด้านบน

### Transport บน 375 px
- ไม่มี bottom nav (role นี้ใช้บนมือถือไม่บ่อย)
- Layout responsive อยู่ — ทำงานได้แต่ desktop ใช้สะดวกกว่า
- การกรอก inspection form ที่ field ขึ้น — มือถือก็กรอกได้

### ทุก role
- ปุ่มหลักขนาด ≥ 44×44 px
- Pinch zoom ปิด (responsive แล้ว)
- Pull-to-refresh ใช้ได้

| Login ไม่ได้ | ตรวจรหัส; ถ้าจำไม่ได้ติดต่อ admin จังหวัด |
| ขึ้น 403 ขณะเปิดโรงเรียนเขตอื่น | นอก scope — ไม่ใช่ bug |
| Dashboard ไม่อัพเดต | F5 / pull-to-refresh; ตรวจสัญญาณ |
| Export ดาวน์โหลดไม่ออก | อนุญาต popup สำหรับ schoolbuslampang.com |
| Map ไม่แสดง pin | ตรวจว่ารถมี GPS update ล่าสุดในระบบ |
| Inspection ที่บันทึกแล้วไม่เห็น | clear filter; ตรวจวันที่กรอกถูก |
| Audit log โหลดช้า | เพิ่ม filter ให้แคบลง (วัน + role) |

หากปัญหายังอยู่ ส่งให้ทีม:
- URL
- timestamp
- screenshot
- บทบาท / username (ไม่ต้องส่งรหัสผ่าน)
