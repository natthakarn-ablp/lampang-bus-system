## 1. บทนำ

ระบบรถรับส่งนักเรียนจังหวัดลำปาง เป็นระบบติดตามการรับ-ส่งนักเรียนโดยรถรับส่ง ครอบคลุมตั้งแต่การเช็กอินประจำวัน การตรวจสภาพรถ ไปจนถึงการรายงานสรุปสำหรับผู้บริหาร

### สิทธิ์ผู้ใช้ 6 ระดับ

| สิทธิ์ | ผู้ใช้ | ขอบเขต |
|--------|--------|--------|
| คนขับรถ | คนขับรถรับส่ง | เช็กอิน/เช็กเอาท์นักเรียนในรถตัวเอง |
| โรงเรียน | ครู/เจ้าหน้าที่โรงเรียน | จัดการข้อมูลนักเรียนและรถของโรงเรียนตนเอง |
| สังกัด | เจ้าหน้าที่เขตพื้นที่การศึกษา | ดูภาพรวมโรงเรียนในสังกัดและจัดการบัญชีโรงเรียน |
| จังหวัด | สภาองค์กรของผู้บริโภค | ดูภาพรวมทั้งจังหวัด (อ่านอย่างเดียว) |
| ขนส่ง | เจ้าหน้าที่ตรวจสภาพรถ | ตรวจสภาพรถและออกใบรับรอง |
| ผู้ดูแลระบบ | ผู้ดูแลระบบ | จัดการทุกส่วนของระบบ |

## 2. วิธีเข้าสู่ระบบ

1. เปิดเว็บไซต์ https://schoolbuslampang.com
2. กรอก **ชื่อผู้ใช้** (สำหรับคนขับ ใช้ทะเบียนรถ เช่น `นข 1571 ลำปาง`)
3. กรอก **รหัสผ่าน**
4. กด **เข้าสู่ระบบ**

### การเปลี่ยนรหัสผ่าน
- หากเข้าสู่ระบบครั้งแรกหรือถูกรีเซ็ตรหัสผ่าน ระบบจะบังคับให้เปลี่ยนรหัสผ่านก่อนเข้าใช้งาน
- รหัสผ่านใหม่ต้องมีอย่างน้อย 6 ตัวอักษร

### ข้อความแจ้งเตือนเมื่อเข้าสู่ระบบไม่ได้

| ข้อความ | ความหมาย |
|---------|----------|
| ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง | ตรวจสอบชื่อผู้ใช้และรหัสผ่านอีกครั้ง |
| บัญชีนี้ถูกปิดการใช้งาน | ติดต่อผู้ดูแลระบบ |
| มีการพยายามเข้าสู่ระบบหลายครั้ง | รอประมาณ 15 นาทีแล้วลองใหม่ — บัญชีไม่ได้ถูกล็อกถาวร |

## 3. สิทธิ์คนขับรถ (Driver)

### เมนูหลัก
| เมนู | หน้าที่ |
|------|---------|
| ภาพรวมวันนี้ | เช็กอินนักเรียน ดูสถานะประจำวัน |
| เลือกรถและเริ่มรอบ | เลือกรถที่ได้รับอนุญาตและบันทึกคนขับจริงของรอบนั้น |
| คำขอรายชื่อ | ดูคำขอเปลี่ยนแปลงรายชื่อนักเรียน |
| แจ้งเหตุฉุกเฉิน | รายงานเหตุฉุกเฉินระหว่างเดินทาง |
| ข้อมูลคนขับ | ดู/แก้ไขข้อมูลส่วนตัว |

### วิธีใช้งานหลัก

**เช็กอินนักเรียน**
1. เข้าหน้า **ภาพรวมวันนี้**
2. ระบบแสดงโหมดปัจจุบัน (ส่งเช้า / รับเย็น) อัตโนมัติ
3. นักเรียนแยกตามโรงเรียน — แต่ละกลุ่มมีสีแยกให้เห็นชัด
4. กดปุ่ม **ส่งถึงโรงเรียน** หรือ **รับกลับบ้าน** ทีละคน
5. หรือกดปุ่ม **ส่งเช้าทั้งหมด / รับเย็นทั้งหมด** เพื่อเช็กอินพร้อมกัน

**บันทึกการลา**
1. กดปุ่ม **ลา** ที่ชื่อนักเรียน
2. เลือก: ลาเช้า / ลาเย็น / ลาทั้งวัน

**ยกเลิกการลา**
1. ในส่วน "ลาวันนี้" กดปุ่ม **↩️ ยกเลิกการลา**

**เลือกคนขับจริงและรถประจำรอบ**
1. เข้าเมนู **เลือกรถและเริ่มรอบ**
2. เลือกรอบเช้า รอบเย็น หรือรอบอื่น
3. ระบบแสดงรถทุกคันที่คนขับได้รับอนุญาต ทั้งสถานะ **คนขับหลัก** และ **คนขับสำรอง**
4. กด **เริ่มขับรถคันนี้** ก่อนปฏิบัติงาน และกด **สิ้นสุดรอบ** เมื่อจบงาน
5. ระบบไม่อนุญาตให้คนขับคนเดียวเปิดสองคันพร้อมกัน หรือให้รถคันเดียวมีสองคนขับพร้อมกัน

> การเริ่มรอบต้องมีบัญชีที่เชื่อมกับข้อมูลคนขับ ใบอนุญาตยังไม่หมดอายุ และรถต้องผ่านเงื่อนไขความปลอดภัย

### ข้อจำกัด
- เห็นเฉพาะนักเรียนในรถตัวเอง
- ไม่สามารถเข้าถึงเมนูของสิทธิ์อื่นได้

## 4. สิทธิ์โรงเรียน (School)

### เมนูหลัก
| เมนู | หน้าที่ |
|------|---------|
| ภาพรวมโรงเรียน | Dashboard สถานะรับ-ส่งวันนี้ |
| ข้อมูลนักเรียน | ค้นหา เพิ่ม แก้ไข นำเข้าข้อมูลนักเรียน |
| รถรับส่ง | ดูรายการรถ คนขับ สถานะตรวจสภาพ ประกัน |
| ส่งตรวจและรับรองรถ | สร้างใบส่งตรวจแบบรวมหลายโรงเรียน พิมพ์เอกสารและติดตามผล |
| คำขอรายชื่อ | อนุมัติ/ปฏิเสธคำขอเปลี่ยนรายชื่อจากคนขับ |
| เพิ่มรถรับส่ง | เพิ่มข้อมูลรถเข้าระบบ |
| เหตุฉุกเฉิน | ดูรายงานเหตุฉุกเฉิน |
| ประวัติการแก้ไข | ดูประวัติการเปลี่ยนแปลงข้อมูล |
| รายงาน | รายงานรายวัน / รายเดือน / สรุป — ส่งออก PDF/Excel/CSV |

### วิธีใช้งานหลัก

**จัดการนักเรียน**
1. เข้าเมนู **ข้อมูลนักเรียน**
2. ค้นหาด้วยชื่อ นามสกุล หรือรหัสนักเรียน
3. กรองตามชั้นเรียน
4. กดปุ่ม **แก้ไข** เพื่อเปลี่ยนข้อมูล ย้ายรถ หรือลบนักเรียน

**นำเข้าข้อมูลนักเรียน**
1. กดปุ่ม **ดาวน์โหลดตัวอย่าง** เพื่อดาวน์โหลดไฟล์แบบฟอร์ม CSV
2. กรอกข้อมูลตามหัวคอลัมน์ภาษาไทย
3. กดปุ่ม **นำเข้าข้อมูล** แล้วเลือกไฟล์

**รถรับส่ง**
- แต่ละคันแสดง: ทะเบียน คนขับ (กดเบอร์โทรเพื่อโทรได้) ผู้ดูแล เจ้าของ
- แสดงสถานะ **ตรวจสภาพรถ** (ผ่าน/ไม่ผ่าน/ยังไม่ตรวจ)
- แสดงสถานะ **ประกันภัย** (ปกติ/ใกล้หมด/หมดแล้ว)

**สร้างใบส่งตรวจรถแบบรวม**
1. เข้าเมนู **ส่งตรวจและรับรองรถ** แล้วเลือกรถที่โรงเรียนมีนักเรียนใช้งาน
2. กด **สร้างใบส่งตรวจ** ระบบรวมจำนวนผู้โดยสารเช้า/เย็นของทุกโรงเรียนที่ใช้รถคันเดียวกัน
3. ตรวจข้อมูลแล้วกด **ยืนยันข้อมูลพร้อมพิมพ์**
4. พิมพ์ใบส่งตรวจพร้อม QR แล้วให้เจ้าของรถนำไปยื่นตรวจตามขั้นตอนของขนส่งจังหวัดลำปาง
5. โรงเรียนที่ใช้รถร่วมกันเปิดดูสถานะคำขอเดียวกันได้ โดยไม่ต้องสร้างเอกสารซ้ำ

เอกสารและข้อมูลที่ส่งให้ขนส่งไม่มีรายชื่อนักเรียน ชื่อผู้ปกครอง เบอร์โทร หรือรหัสประจำตัว แสดงเฉพาะจำนวนแยกโรงเรียน/รอบรถ ข้อมูลรถ คนขับที่ได้รับอนุญาต และพื้นที่รับส่งโดยสรุป

**ส่งออกรายงาน**
- เข้าเมนู **รายงาน** → เลือกรายวัน / รายเดือน / สรุป
- กดปุ่มส่งออก PDF / Excel / CSV

### ข้อจำกัด
- เห็นเฉพาะข้อมูลของโรงเรียนตนเอง
- ไม่สามารถเข้าถึงข้อมูลโรงเรียนอื่นหรือสิทธิ์อื่นได้

## 5. สิทธิ์สังกัด (Affiliation)

### เมนูหลัก
| เมนู | หน้าที่ |
|------|---------|
| ภาพรวมสังกัด | Dashboard สรุปทุกโรงเรียนในสังกัด |
| ข้อมูลนักเรียน | ค้นหานักเรียนทุกโรงเรียนในสังกัด |
| รถรับส่ง | ดูรถทุกคันที่ให้บริการโรงเรียนในสังกัด |
| จัดการบัญชีโรงเรียน | สร้างบัญชีผู้ใช้โรงเรียน / รีเซ็ตรหัสผ่าน |
| เหตุฉุกเฉิน | ดูรายงานเหตุฉุกเฉิน |
| ประวัติการแก้ไข | ดูประวัติการเปลี่ยนแปลงข้อมูล |
| รายงาน | รายงานรายวัน / รายเดือน / สรุป |

### หน้าภาพรวมสังกัด
- **กราฟสถานะส่งเช้า / รับเย็น** ขนาดใหญ่ แสดง % และจำนวนคน
- **โรงเรียนที่ยังมีรายการค้าง** แสดงแถบสี:
  - เขียว = ส่งแล้ว
  - แดง = รอ
  - แสดงจำนวนนักเรียน รถรับส่ง และตัวเลข done/pending ต่อโรงเรียน

### จัดการบัญชีโรงเรียน
1. สร้างบัญชีผู้ใช้ให้โรงเรียนใหม่ได้
2. รีเซ็ตรหัสผ่านโรงเรียนได้ (ผู้ใช้จะต้องเปลี่ยนรหัสผ่านเมื่อ login ครั้งถัดไป)
3. เปิด/ปิดการใช้งานบัญชีได้

### ข้อจำกัด
- เห็นเฉพาะโรงเรียนในสังกัดตนเอง
- ไม่สามารถแก้ไขข้อมูลนักเรียนหรือรถโดยตรง

## 6. สิทธิ์จังหวัด (Province)

### เมนูหลัก
| เมนู | หน้าที่ |
|------|---------|
| ภาพรวมจังหวัด | Dashboard สรุปทุกสังกัด ทุกโรงเรียน ทุกรถ |
| สังกัด | ดูรายการสังกัดทั้งหมด |
| โรงเรียน | ดูรายชื่อโรงเรียนทั้งจังหวัด |
| ข้อมูลนักเรียน | ค้นหานักเรียนทั้งจังหวัด |
| รถรับส่ง | ดูรถทุกคันในจังหวัด |
| ความพร้อมเปิดใช้งาน | สรุปสถานะความพร้อมของรถและคนขับทั้งจังหวัด |
| เหตุฉุกเฉิน | ดูรายงานเหตุฉุกเฉิน |
| ประวัติการแก้ไข | ดูประวัติการเปลี่ยนแปลงข้อมูล |
| รายงาน | รายงานรายวัน / รายเดือน / สรุป |

### หน้าภาพรวมจังหวัด
- **ภาพรวมรถรับส่ง**: จำนวนรถ นักเรียน โรงเรียน สังกัด
- **KPI ส่งเช้า / รับเย็น**: กราฟวงกลมขนาดใหญ่
- **โรงเรียนที่ยังมีรายการค้าง**: แถบสีเขียว/แดง ต่อโรงเรียน
- **สรุปรายสังกัด**: KPI ต่อสังกัด
- **สรุปผู้บริหาร**: ข้อความสรุปอัตโนมัติ

### หน้าความพร้อมเปิดใช้งาน (เพิ่ม 2026-06-22)
1. เข้าเมนู **ความพร้อมเปิดใช้งาน** (`/province/readiness`)
2. เห็น bucket สรุประดับจังหวัด:
   - รถทั้งหมด แยกตามสถานะ (UNVERIFIED / ELIGIBLE / EXPIRING / INELIGIBLE / SUSPENDED)
   - รถที่มี certified capacity / ผลตรวจ PASSED ล่าสุด / เอกสารยังใช้ได้
   - บัญชีคนขับที่ผูก `driver_id` vs ยังไม่ผูก
   - คนขับที่ qualification VERIFIED และใบอนุญาตยังไม่หมดอายุ
   - รถที่มีคนขับ AUTHORIZED อย่างน้อยหนึ่งคน
3. ตาราง "gap" แสดงรายการที่ยังขาด พร้อมผู้รับผิดชอบและการดำเนินการต่อไป
4. หน้านี้ **อ่านอย่างเดียว** ไม่มี PII (เฉพาะตัวเลขรวมและ label)
5. ปัจจุบันเป็น aggregate ระดับจังหวัด ยังไม่มี drill-down รายโรงเรียน/รายเขต

### ข้อจำกัด
- **อ่านอย่างเดียว** — ไม่สามารถแก้ไข สร้าง ลบ หรือรีเซ็ตข้อมูลใดได้
- ส่งออกรายงานได้

## 7. สิทธิ์ขนส่ง (Transport)

### เมนูหลัก
| เมนู | หน้าที่ |
|------|---------|
| ภาพรวมตรวจสภาพรถ | Dashboard แสดงรถเสี่ยง/ยังไม่ตรวจ/ประกัน |
| ตรวจรับรองรถ | เปิดคิวใบส่งตรวจรวม ตรวจตาม checklist และลงผลรับรอง |
| บันทึกตรวจสภาพ | บันทึกผลตรวจและออกใบรับรอง |

### หน้าภาพรวม (Executive Dashboard)
- **แจ้งเตือนด้านบน**: จำนวนรถเสี่ยงเร่งด่วน
- **ตัวกรองด่วน**: กดเลือก เร่งด่วน / ยังไม่ตรวจ / ไม่ผ่าน / ประกันหมด / พร้อมใช้งาน ฯลฯ
- **รายการรถ**: แสดงสถานะ + ปุ่ม "📝 บันทึกตรวจ" และ "📞 โทรคนขับ"
- **กราฟ**: ผลตรวจสภาพ (วงกลม) + สถานะประกัน (แท่ง)

### บันทึกผลตรวจ
1. เลือกรถจากรายการ หรือเลือก **"อื่นๆ"** เพื่อเพิ่มรถใหม่
2. ถ้าเพิ่มรถใหม่: กรอก เลขนำหน้า / หมวดอักษร / หมายเลข / จังหวัด
3. เลือกผลตรวจ: ผ่าน / ไม่ผ่าน / ต้องแก้ไข / รอตรวจ
4. เลือก **โรงเรียนที่ออกใบรับรอง** หรือเลือก "อื่นๆ" เพื่อพิมพ์ชื่อเอง
5. กรอกวันที่ตรวจ / วันหมดอายุ / หมายเหตุ
6. กด **บันทึก**
7. ระบบกลับไปหน้า Dashboard และไฮไลต์รถที่เพิ่งบันทึก

### ตรวจรับรองรถจากใบส่งตรวจรวม
1. เข้าเมนู **ตรวจรับรองรถ** ค้นหาด้วยทะเบียน เลขคำขอ หรือโรงเรียน
2. เปิดรายละเอียดเพื่อตรวจข้อมูลรถ ความจุ จำนวนผู้โดยสารสูงสุด โรงเรียน พื้นที่รับส่ง และคนขับหลัก/สำรอง
3. กด **เริ่มการตรวจครั้งใหม่** ทุกครั้งที่รถเข้าตรวจ ประวัติครั้งก่อนจะไม่ถูกแก้ทับ
4. ระบุผลทุกหัวข้อใน checklist; หัวข้อที่ไม่ผ่านต้องเขียนรายละเอียด
5. เลือกผลรวม **ผ่าน / ต้องแก้ไข / ไม่ผ่าน / รอข้อมูลเพิ่ม** และกรอกวันหมดอายุเมื่อผลเป็น “ผ่าน”
6. ระบบอัปเดตสถานะรถอัตโนมัติจากผลตรวจ เอกสาร ความจุผู้โดยสาร และจำนวนคนขับที่คุณสมบัติยังใช้ได้

ระบบปัจจุบันเป็นการรับรองโดยเจ้าหน้าที่ขนส่งจังหวัดในระบบ อบจ. โดยไม่พึ่ง API ส่วนกลาง ช่องทาง `provider_type` รองรับการเชื่อม DLT Central API หรือไฟล์ลงนามในอนาคตโดยไม่ต้องเปลี่ยนโครงสร้างคำขอเดิม

### Deep-link จาก Dashboard
- กดปุ่ม **"📝 บันทึกตรวจ"** ที่รถคันใด → ระบบเปิดฟอร์มพร้อมเลือกรถให้แล้ว

### ข้อจำกัด
- ไม่สามารถเข้าถึงข้อมูลนักเรียนหรือเมนูของสิทธิ์อื่นได้

### การจัดการโรงเรียน/สังกัด (Admin Context Switching)
- เมื่อเข้าเมนู 🏫 จัดการโรงเรียน จะมี **แถบเลือกโรงเรียน** แสดงด้านบน
- เลือกโรงเรียนแล้วระบบจะแสดงข้อมูลเฉพาะโรงเรียนนั้น
- เมื่อเข้าเมนู 🔑 จัดการบัญชีโรงเรียน จะมี **แถบเลือกสังกัด** แสดงด้านบน

### คำขอโอนย้ายนักเรียน (เพิ่ม Phase 10.13B)
1. เข้าเมนู **👥 คำขอโอนย้ายนักเรียน** (`/admin/transfer-requests`)
2. ดูรายการคำขอ (รออนุมัติ / อนุมัติแล้ว / ไม่อนุมัติ)
3. ระบบแสดงคำเตือน: **รหัสซ้ำในโรงเรียนปลายทาง** และ **นักเรียนมีรถอยู่**
4. **อนุมัติ** (Option B): ปิดนักเรียนต้นทาง (soft-close) + สร้างนักเรียนปลายทางใหม่
   (รหัสใหม่อัตโนมัติ คัดลอกผู้ปกครอง ไม่ผูกรถ)
5. ถ้าโรงเรียนปลายทางมีรหัสนักเรียนซ้ำ → ระบบ **บล็อก** (FAILED)
6. **ไม่อนุมัติ** ต้องใส่หมายเหตุ · การอนุมัติซ้ำปลอดภัย (idempotent)

### คำขอเกี่ยวกับรถ (เพิ่ม Phase 10.13B)
1. เข้าเมนู **🔧 คำขอเกี่ยวกับรถ** (`/admin/vehicle-requests`)
2. **ขอกู้คืนรถ (RESTORE)**: อนุมัติแล้วระบบกู้คืนรถเดิม (is_deleted=false)
   - ถ้ามีรถทะเบียนเดียวกันใช้งานอยู่ → **บล็อก**
3. **ขอใช้รถ / ขอเพิ่มรถ / ขอตรวจสอบ**: เป็นข้อมูลแจ้งเพื่อทราบ (informational)

### สุขภาพข้อมูลคนขับ (เพิ่ม Phase 10.13B)
1. เข้าเมนู **🚨 สุขภาพข้อมูลคนขับ** (`/admin/driver-integrity`)
2. แดชบอร์ด: รถยังไม่มีคนขับ / คนขับยังไม่มีรถ / บัญชีซ้ำ-ถูกปิด / ยังไม่ผูกโปรไฟล์
3. เครื่องมือจัดการคนขับ (กรอก user id → **ตรวจสอบก่อนดำเนินการ**):
   - **กู้คืนบัญชีคนขับ** — อนุญาตเฉพาะบัญชีหลัก (canonical)
   - **ย้ายคนขับไปรถใหม่** — สิ้นสุดงานเดิม + สร้างงานใหม่
   - **ปิดใช้งานคนขับ** — สิ้นสุดงาน + ปิดบัญชี (ไม่ลบประวัติ)
4. ทุกการกระทำต้องใส่เหตุผล และถูกบันทึกประวัติ

### จุดเตือนภัย / Geofences (เพิ่ม Phase 11A — 2026-06-23)

> ต้องเปิด `FEATURE_GEOFENCE=true` ใน `.env` และรัน migration 040 ก่อน

1. เข้าเมนู **📍 จุดเตือนภัย (Geofences)** (`/admin/geofences`)
2. หน้าจอแสดง 2 ส่วน:
   - **รายการ geofences** — แต่ละจุดมีชื่อ ประเภท (PICKUP/SCHOOL/CUSTOM) รัศมี (เมตร) สถานะ active
   - **Event log** — รายการล่าสุด 50 events (ENTER/EXIT) พร้อมจำนวนการแจ้งเตือนที่ส่งออก
3. **สร้างอัตโนมัติ**:
   - กดปุ่ม **"สร้าง geofences อัตโนมัติ"**
   - ระบบจะสร้าง geofence รอบจุดรับ-ส่งทุกจุด (150m) และโรงเรียนทุกแห่ง (300m) ที่ยังไม่มี
4. **สร้างเอง**:
   - กด **"เพิ่ม geofence"** → กรอกชื่อ ประเภท ละติจูด ลองจิจูด รัศมี
5. **เปิด/ปิด**: กด toggle → geofence ยังอยู่ในระบบแต่ไม่ trigger
6. **ลบ**: กดปุ่มลบ → soft delete (`is_active=FALSE`)
7. เมื่อรถเข้า/ออก geofence → ระบบบันทึก event และส่ง LINE push ไปยังผู้ปกครองของนักเรียนในรถนั้น

### การเบี่ยงเส้นทาง / Route Deviations (เพิ่ม Phase 11A — 2026-06-23)

> ต้องเปิด `FEATURE_ROUTE_DEVIATION=true` และมี `route_baselines` อย่างน้อย 3 วัน (จาก nightly job)

1. เข้าเมนู **🛣️ การเบี่ยงเส้นทาง** (`/admin/route-deviations`)
2. หน้าจอแสดงตาราง deviations พร้อมตัวกรอง:
   - **สถานะ**: ทั้งหมด / ยังไม่ resolved / resolved
   - **ประเภท**: STALLED / OFF_ROUTE / LATE
   - **ระดับความรุนแรง** (severity): low / medium / high
3. ประเภทการเบี่ยงเส้นทาง:
   - **STALLED** — รถหยุดนิ่ง > 15 นาที ขณะไม่อยู่ใน geofence (รถเสีย / ติดจราจรหนักมาก)
   - **OFF_ROUTE** — รถเบี่ยง > 500m จากเส้นทางปกติ (เทียบกับ baseline 3 วัน)
   - **LATE** — รถล่าช้า > 10 นาที จากเวลาถึงจุดเฉลี่ย
4. เมื่อรถกลับเส้นทางปกติ → ระบบ auto-resolve (`resolved_at` ไม่เป็น NULL)
5. ผู้ดูแลระบบสามารถ mark resolved เองได้ (ผ่าน API ในอนาคต)
6. ทุก deviation ส่ง alert ไปยัง `ALERT_LINE_WEBHOOK_URL` (ถ้าตั้งค่าไว้)

### ความพร้อมเปิดใช้งาน (เพิ่ม 2026-06-22)
- เข้าเมนู **🛡️ ความพร้อมเปิดใช้งาน** (`/admin/readiness`)
- เห็นหน้าเดียวกับ province — อ่านอย่างเดียว ไม่มี PII

### จัดการผู้ใช้งาน
1. เข้าเมนู **👤 จัดการผู้ใช้งาน**
2. ค้นหาหรือกรองตามบทบาท
3. **สร้างผู้ใช้ใหม่**: กรอกชื่อผู้ใช้ รหัสผ่าน บทบาท หน่วยงาน
4. **แก้ไข**: เปลี่ยนชื่อแสดง เปิด/ปิดบัญชี
5. **รีเซ็ตรหัสผ่าน**: ตั้งรหัสผ่านใหม่ — ผู้ใช้จะถูกบังคับเปลี่ยนเมื่อ login ครั้งถัดไป
6. **ลบ**: ลบผู้ใช้ออกจากระบบ (soft delete)

### ความแตกต่างจากสิทธิ์จังหวัด
- จังหวัด = **อ่านอย่างเดียว**
- ผู้ดูแลระบบ = **อ่าน + แก้ไข + จัดการผู้ใช้ + ดู audit log**

## 9. ผู้ปกครอง (LINE OA)

ผู้ปกครองใช้งานผ่าน **LINE Official Account** โดยไม่ต้องเข้าเว็บไซต์

### คำสั่งที่ใช้ได้ (พิมพ์ในแชท LINE)

| คำสั่ง | หน้าที่ |
|--------|---------|
| ผูกบัญชี | เชื่อมข้อมูลบุตรหลาน |
| สถานะ | ดูสถานะรับ-ส่งวันนี้ |
| ข้อมูลบุตร | ดูข้อมูลนักเรียนที่ผูกไว้ |
| ยกเลิกผูกบัญชี | ยกเลิกการเชื่อม (ต้องยืนยัน) |
| เปลี่ยนบัญชี | เปลี่ยนเป็นผู้ปกครองอื่น (ต้องยืนยัน) |
| ช่วยเหลือ | แสดงเมนูคำสั่ง |

### วิธีผูกบัญชี
1. เพิ่มเพื่อน LINE OA ของระบบ
2. พิมพ์ **"ผูกบัญชี"**
3. กรอก **เบอร์โทร** ที่ลงทะเบียนไว้กับโรงเรียน
4. กรอก **รหัสนักเรียน** ของบุตรหลาน
5. รอโรงเรียนอนุมัติ

### หมายเหตุ
- LINE 1 บัญชีผูกได้กับผู้ปกครอง 1 คนเท่านั้น
- ผู้ปกครอง 1 คนดูบุตรหลายคนข้ามโรงเรียนได้
- การยกเลิกหรือเปลี่ยนบัญชีต้องยืนยัน 2 ขั้นตอน

### ดู ETA รถ (เพิ่ม Phase 11A — 2026-06-23)

> ต้องเปิด `FEATURE_ETA=true` และคนขับเปิด live location ในแอป

1. เปิดหน้าสถานะบุตรหลานใน LIFF
2. ในการ์ดนักเรียนแต่ละคน จะมีปุ่ม **"📍 ETA"**
3. กดปุ่ม → ระบบแสดง:
   - **เวลาถึงโดยประมาณ** (นาที) ต่อจุดรับ-ส่ง
   - **ระยะทาง** จากตำแหน่งรถปัจจุบัน
   - **ระดับความมั่นใจ** (high / medium / low) — ขึ้นกับอายุของ GPS และความสม่ำเสมอ
4. กด **"รีเฟรช ETA"** เพื่ออัปเดตข้อมูลใหม่ล่าสุด
5. ถ้ารถออฟไลน์ / คนขับยังไม่เปิด location → แสดง "ยังไม่มีข้อมูล ETA"

### รับแจ้งเตือน Geofence (เพิ่ม Phase 11A — 2026-06-23)

> ต้องเปิด `FEATURE_GEOFENCE=true` และ admin สร้าง geofences แล้ว

- เมื่อรถของบุตรหลานเข้าใกล้จุดรับ-ส่ง (รัศมี 150m) → ผู้ปกครองได้รับ **LINE push** "รถถึงจุด ... แล้ว"
- เมื่อรถถึงโรงเรียน (รัศมี 300m) → ได้รับ push "รถถึงโรงเรียนแล้ว"
- ไม่ต้องตั้งค่าอะไรเพิ่ม — ส่งอัตโนมัติเมื่อฟีเจอร์เปิด

## 10. แนวปฏิบัติเมื่อพบปัญหา

### เข้าสู่ระบบไม่ได้
- ตรวจสอบชื่อผู้ใช้และรหัสผ่าน
- ถ้าเห็น "มีการพยายามเข้าสู่ระบบหลายครั้ง" → รอ 15 นาทีแล้วลองใหม่
- ถ้าลืมรหัสผ่าน → ติดต่อผู้ดูแลระบบเพื่อรีเซ็ต

### ข้อมูลไม่ตรง
- ตรวจสอบว่าเลือกวันที่ถูกต้อง
- ระบบรีเฟรชอัตโนมัติทุก 30 วินาทีสำหรับหน้าคนขับ
- ถ้าข้อมูลยังไม่ตรง → ลองรีเฟรชหน้าเว็บ

### PDF ภาษาไทยอ่านไม่ได้
- ปัญหานี้แก้ไขแล้ว — ระบบใช้ฟอนต์ Sarabun สำหรับ PDF
- ถ้ายังมีปัญหา → เปิด PDF ด้วย Adobe Acrobat หรือ Chrome

### LINE OA ไม่ตอบ
- ตรวจสอบว่าเพิ่มเพื่อน LINE OA ถูกบัญชี
- ลองพิมพ์ "ช่วยเหลือ" อีกครั้ง

### ต้องการความช่วยเหลือ
- ติดต่อผู้ดูแลระบบ
- หรือแจ้งผ่านช่องทางที่หน่วยงานกำหนด
