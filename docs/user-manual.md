# คู่มือใช้งานระบบรถรับส่งนักเรียนจังหวัดลำปาง

> ระบบรถรับส่งนักเรียนจังหวัดลำปาง — เว็บไซต์ **https://schoolbuslampang.com**
> เวอร์ชัน Phase 10.13C • อัปเดต 2026-06-24

เอกสารนี้เป็น **สารบัญหลัก** ของคู่มือใช้งาน แยกตามสิทธิ์ (role) แต่ละสิทธิ์มีคู่มือเฉพาะของตนเองที่จัดทำโดยอ้างอิงจากโค้ดจริงของระบบ คลิกที่ชื่อสิทธิ์เพื่อเปิดคู่มือฉบับเต็ม

สำหรับการอบรม/นำส่งหน่วยงาน ให้ใช้ชุดคู่มือใหม่ที่แยกสิทธิ์ย่อยชัดเจน พร้อมภาพประกอบและ checklist ตรวจรับท้ายบท:

- [เปิดสารบัญชุดคู่มืออบรม](manual-training-2026-08/README.md)
- แยกสิทธิ์เพิ่มเติมจากคู่มือเดิม: **โรงเรียนเต็มสิทธิ์** และ **ครูประจำสายชั้น**
- เหมาะสำหรับแจกผู้ใช้งานแต่ละกลุ่มก่อน UAT หรือวันอบรมจริง

## 1. ภาพรวมระบบ

ระบบรถรับส่งนักเรียนจังหวัดลำปาง เป็นระบบติดตามการรับ-ส่งนักเรียนโดยรถรับส่ง ครอบคลุมตั้งแต่การเช็กชื่อขึ้น-ลงรถประจำวัน การตรวจสภาพรถ การแจ้งเตือนผู้ปกครองผ่าน LINE ไปจนถึงรายงานสรุปสำหรับผู้บริหารทุกระดับ มีการแบ่งสิทธิ์ผู้ใช้ออกเป็น 7 ระดับ แต่ละระดับเห็นและทำได้เฉพาะในขอบเขตของตน (ระบบบังคับสิทธิ์ที่ฝั่งเซิร์ฟเวอร์)

## 2. การเข้าสู่ระบบ (ใช้ร่วมทุกสิทธิ์ ยกเว้นผู้ปกครอง)

1. เปิดเบราว์เซอร์ (Chrome / Safari) ไปที่ **https://schoolbuslampang.com**
2. กรอก **ชื่อผู้ใช้**
   - คนขับ → ใช้ **ทะเบียนรถ** ของตน (เช่น `นข 1571 ลำปาง` — เว้นวรรคให้ตรง)
   - สิทธิ์อื่น → ใช้ชื่อผู้ใช้ที่ได้รับจากหน่วยงาน/ผู้ดูแลระบบ
3. กรอก **รหัสผ่าน** แล้วกด **เข้าสู่ระบบ**

> ผู้ปกครองไม่ได้เข้าผ่านเว็บไซต์ — ใช้งานผ่าน LINE Official Account เท่านั้น (ดู [คู่มือผู้ปกครอง](user-guide-parent.md))

### การเปลี่ยนรหัสผ่าน
- เข้าครั้งแรก หรือเมื่อถูกผู้ดูแลรีเซ็ตรหัส → ระบบ**บังคับเปลี่ยนรหัสผ่าน**ก่อนใช้งาน
- **รหัสผ่านใหม่ต้องยาวอย่างน้อย 8 ตัวอักษร** ห้ามตรงกับชื่อผู้ใช้ ห้ามเป็นรหัสที่เดาง่าย (เช่น `12345678`, `password`) และห้ามเป็นตัวอักษรเดียวซ้ำกันทั้งหมด
- เปลี่ยนรหัสเองภายหลังได้จากเมนูบัญชีผู้ใช้ (มุมขวาบน) → **เปลี่ยนรหัสผ่าน**

### ลืมรหัสผ่าน
- **ไม่มี**ระบบรีเซ็ตรหัสด้วยตนเอง — ต้องให้ผู้ที่มีสิทธิ์รีเซ็ตให้:
  - บัญชีโรงเรียน/ครู → ผู้ดูแลระบบ (admin)
  - บัญชีอื่น ๆ → ผู้ดูแลระบบ (admin)

### ข้อความแจ้งเตือนเมื่อเข้าสู่ระบบไม่ได้

| ข้อความ | ความหมาย/วิธีแก้ |
|---------|------------------|
| ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง | ตรวจสอบชื่อผู้ใช้/รหัสผ่านอีกครั้ง (คนขับ: ดูการเว้นวรรคทะเบียนรถ) |
| บัญชีนี้ถูกปิดการใช้งาน | ติดต่อผู้ดูแลระบบ |
| มีการพยายามเข้าสู่ระบบหลายครั้ง | รอประมาณ 15 นาทีแล้วลองใหม่ — บัญชีไม่ได้ถูกล็อกถาวร |

## 3. หมายเหตุเรื่องฟีเจอร์ที่ต้องเปิดใช้งานก่อน (Feature Flags)

ระบบมีฟีเจอร์ขั้นสูงบางส่วนที่ **ปิดอยู่โดยค่าเริ่มต้น** ในการใช้งานจริง และจะปรากฏก็ต่อเมื่อผู้ดูแลเปิด feature flag ที่เซิร์ฟเวอร์ ในคู่มือรายสิทธิ์ ฟีเจอร์เหล่านี้จะมีเครื่องหมาย ⚠️ กำกับไว้ ได้แก่:

| ฟีเจอร์ | flag | สถานะปัจจุบัน |
|---------|------|----------------|
| เลือกรถ/เริ่มรอบของคนขับ (driver shift) | `FEATURE_DRIVER_SHIFT_SELECTION` | ปิด |
| ETA เวลารถถึง (ผู้ปกครอง) | `FEATURE_ETA` | ปิด |
| จุดเตือนภัย / Geofence | `FEATURE_GEOFENCE` | ปิด |
| การเบี่ยงเส้นทาง / Route deviation | `FEATURE_ROUTE_DEVIATION` | ปิด |
| QR ที่ตัวรถ + ความยินยอม PDPA | `FEATURE_VEHICLE_QR` | ปิด |

> ฟีเจอร์ที่ "พร้อมใช้งานจริง" ได้แก่ การเช็กชื่อขึ้น-ลงรถ, ตรวจสภาพรถ/ใบรับรอง, จัดการนักเรียน/รถ, รายงานและการส่งออก, แดชบอร์ดทุกระดับ, การผูกบัญชี/แจ้งเตือนผู้ปกครองผ่าน LINE, แผนที่จุดรับ-ส่ง และตำแหน่งรถแบบ live

## 4. แนวปฏิบัติเมื่อพบปัญหา (ทั่วไป)

### เข้าสู่ระบบไม่ได้
- ตรวจสอบชื่อผู้ใช้/รหัสผ่าน — ถ้าขึ้น "มีการพยายามเข้าสู่ระบบหลายครั้ง" ให้รอ ~15 นาที
- ลืมรหัส → ติดต่อผู้ดูแลระบบเพื่อรีเซ็ต

### ข้อมูลไม่อัปเดต
- ตรวจว่าเลือกวันที่ถูกต้อง
- บางหน้ารีเฟรชอัตโนมัติ (เช่น ตำแหน่งรถ live ทุก ~15 วินาที) — ถ้ายังไม่ตรง ให้รีเฟรชหน้าเว็บ

### PDF ภาษาไทยอ่านไม่ได้
- ระบบฝังฟอนต์ Sarabun ใน PDF แล้ว — หากยังเพี้ยน ให้เปิดด้วย Chrome หรือ Adobe Acrobat

### LINE OA ไม่ตอบ (ผู้ปกครอง)
- ตรวจว่าเพิ่มเพื่อน LINE OA ถูกบัญชี แล้วลองพิมพ์ **"ช่วยเหลือ"** อีกครั้ง

### ต้องการความช่วยเหลือ
- ติดต่อผู้ดูแลระบบ หรือแจ้งผ่านช่องทางที่หน่วยงานกำหนด
